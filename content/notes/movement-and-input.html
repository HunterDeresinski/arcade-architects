How to make something move when the player presses a key. Builds on GDScript Basics.

#Day 1 tutorial: movement on an Area2D

Dodge the Creeps uses Area2D (not CharacterBody2D) for the player. The movement lives in _process() and moves the position directly:

extends Area2D

@export var speed = 400
var screen_size

func _ready():
	screen_size = get_viewport_rect().size

func _process(delta):
	var velocity = Vector2.ZERO
	if Input.is_action_pressed("move_right"):
		velocity.x += 1
	if Input.is_action_pressed("move_left"):
		velocity.x -= 1
	if Input.is_action_pressed("move_down"):
		velocity.y += 1
	if Input.is_action_pressed("move_up"):
		velocity.y -= 1

	if velocity.length() > 0:
		velocity = velocity.normalized() * speed

	position += velocity * delta
	position = position.clamp(Vector2.ZERO, screen_size)
  • velocity.normalized() — keeps diagonal movement from being faster than straight movement.
  • position += velocity * delta — moves the node directly (no physics engine involved).
  • clamp() — prevents the player from leaving the screen.
🗒️Why Area2D here?

Dodge the Creeps uses Area2D because it only needs overlap detection (hits), not physics collision. It's a simplified setup good for a first project.

#Day 3+ games: movement on a CharacterBody2D

For your own team game, CharacterBody2D with move_and_slide() is the better pattern — it handles walls and slopes properly:

extends CharacterBody2D

@export var speed = 400

func _physics_process(delta):
	var direction = Vector2.ZERO
	if Input.is_action_pressed("ui_right"):
		direction.x += 1
	if Input.is_action_pressed("ui_left"):
		direction.x -= 1
	if Input.is_action_pressed("ui_down"):
		direction.y += 1
	if Input.is_action_pressed("ui_up"):
		direction.y -= 1

	velocity = direction.normalized() * speed
	move_and_slide()
  • _physics_process — runs at a fixed rate, better for physics-based movement.
  • move_and_slide() — moves the body and handles wall collisions automatically.

#A simple enemy that moves on its own (patrol)

The easiest self-moving enemy: walk one direction, turn around at walls.

Where it goes: a new scene with CharacterBody2D as root (rename it Enemy), plus a Sprite2D and CollisionShape2D as children — same structure as your player. Attach this script to the Enemy root:

extends CharacterBody2D

@export var speed = 100
var direction = 1

func _physics_process(delta):
	velocity.x = speed * direction
	move_and_slide()
	if is_on_wall():
		direction *= -1
  • is_on_wall() — true when move_and_slide() just hit something solid.
  • direction *= -1 — flips 1 to -1 and back, reversing the walk.
  • It needs something solid to bounce off: place two StaticBody2D walls (each with its own CollisionShape2D) at the ends of the patrol path, or use your level's edges.
  • For up-and-down patrol, use velocity.y instead of velocity.x.

Save the scene as enemy.tscn and instance it into your Main scene wherever you want a patroller.

#Detecting a single press (not held)

Use this for jumps, shooting, "press to start":

func _process(delta):
	if Input.is_action_just_pressed("ui_accept"):  # Spacebar / Enter
		print("Jump!")

is_action_pressed = held down. is_action_just_pressed = the frame you press it. Big difference.

#Make your own buttons

Project → Project Settings → Input Map. Add an action (e.g. flap), assign a key. Then Input.is_action_just_pressed("flap"). Great for a one-button game.

💡To change how fast it feels

Change one number: @export var speed. With @export, you can even tune it live in the Inspector — no code edit needed.
