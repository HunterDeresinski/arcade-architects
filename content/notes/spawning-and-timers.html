How to make enemies/coins appear over time. Combines instancing, Timer nodes, and Signals.

#A Timer that does something repeatedly

  1. Add a Timer node.
  2. In the Inspector: set Wait Time (e.g. 1.0 second), check Autostart, check One Shot = off (so it repeats).
  3. Connect its timeout signal (Signals) to a function:
func _on_timer_timeout():
	spawn_enemy()

#Spawning a scene (instancing in code)

First, make the thing its own scene (Scenes and Nodes → Save Branch as Scene). Then preload and spawn copies:

extends Node2D

@export var enemy_scene: PackedScene   # drag Enemy.tscn here in the Inspector

func spawn_enemy():
	var enemy = enemy_scene.instantiate()      # make a copy
	enemy.position = Vector2(randi() % 480, 0) # random x, top of screen
	add_child(enemy)                           # put it in the game
  • instantiate() = make one copy of the scene.
  • add_child() = actually place it into the running game.
  • randi() % 480 = a random number 0–479 (random horizontal spot).

#Making the enemy move on its own

On the Enemy scene's script:

extends Area2D

@export var fall_speed = 200

func _process(delta):
	position.y += fall_speed * delta   # move down every frame
	if position.y > 720:               # off the bottom of the screen?
		queue_free()                   # delete it so it doesn't pile up
⚠️Always clean up

If you spawn things but never queue_free() them when they leave the screen, you'll have thousands of invisible nodes and the game will slow to a crawl.

#Speeding up over time (game gets harder)

func _on_difficulty_timer_timeout():
	$Timer.wait_time = max(0.2, $Timer.wait_time - 0.1)  # spawn faster, floor at 0.2s

$Timer means "the child node named Timer." max(...) stops it getting impossibly fast.

💡Random values (Godot 4)

randi() = random whole number. randf() = random decimal 0–1. randi() % N = 0 to N-1. randf_range(a, b) = random decimal between a and b. Array.pick_random() = random item from a list. In Godot 4, the random seed is automatically randomized — you do not need to call randomize() in _ready().
