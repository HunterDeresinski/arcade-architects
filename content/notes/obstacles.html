Walls, crates, pillars — things the player bumps into instead of dying to. This is the piece that turns an open field into a level. The obstacles that do kill you are Hazards; the full layer system is in CharacterBody2D.

#The catch: Area2D can't be blocked

In Dodge the Creeps the player is an Area2D. Areas detect overlaps but have no physical presence — nothing can stop them. Walk straight through your beautiful wall.

The fix is to change the player's root node type:

  1. Right-click the Player node in the Scene dock → Change Type → CharacterBody2D.
  2. Update the movement script to use the built-in velocity and move_and_slide() (below).

Everything else about the player — the sprite, the shape, the animations — stays exactly as it is.

#Step 1: name your collision layers

Project → Project Settings → Layer Names → 2D Physics. Naming them once means you never have to remember what "Layer 3" was. Use the camp-wide scheme from Collision Layers and Masks — for this note you only need the first three: 1 player, 2 mobs, 3 obstacles.

#Step 2: the new player script

extends CharacterBody2D

signal hit
@export var speed = 400
var screen_size

func _ready():
	screen_size = get_viewport_rect().size

func _physics_process(delta):
	var input_dir = Input.get_vector("move_left", "move_right", "move_up", "move_down")
	velocity = input_dir * speed
	move_and_slide()
	position = position.clamp(Vector2.ZERO, screen_size)

	# your existing animation code stays the same
	if velocity.length() > 0:
		$AnimatedSprite2D.play()
	else:
		$AnimatedSprite2D.stop()
  • velocity is built in on CharacterBody2D — you don't declare it, you just set it.
  • move_and_slide() does the moving and the sliding along walls. Don't also set position from the input; pick one.
  • Set the player's collision Mask to obstacles only. That way move_and_slide() stops you at walls but you don't physically shove the mobs around like bumper cars.

#Step 3: hit detection moves to a Hurtbox

The player no longer detects mobs by itself, so give it a child that does. Add an Area2D child named Hurtbox with its own CollisionShape2D. Set the Hurtbox's Mask to the mobs layer, connect its body_entered signal (Signals), and move your death code there:

func _on_hurtbox_body_entered(body):
	hide()
	hit.emit()
	$Hurtbox/CollisionShape2D.set_deferred("disabled", true)

set_deferred("disabled", true) turns the hurtbox off safely — disabling a shape directly in the middle of a collision throws an error.

#Step 4: the obstacle itself

Dead simple, and no script at all:

Wall            (StaticBody2D)    Layer: obstacles, Mask: (none)
├── Sprite      (Sprite2D)
└── Shape       (CollisionShape2D)

Save as wall.tscn and drag as many copies into your level as you want. It blocks the player because the player's mask includes obstacles. It doesn't kill anyone because it isn't on the mobs layer.

💡Lots of walls? Use a TileMap instead

Hand-placing twenty StaticBody2Ds is slow. Once a level has more than a handful of walls, paint them with collision-enabled tiles instead — see TileMapLayer.
