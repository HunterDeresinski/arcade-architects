How to turn your project into something other people can play — for the showcase and to take home. Do this well before the 3 PM Friday deadline; export always takes longer than you expect.

#Option A — run from the editor (simplest, fine for the showcase)

Just open the project on the demo machine and press ▶ Play. No export needed. This is the safest path if exports are giving trouble — the game runs exactly as it does for you.

#Option B — export a standalone build

Makes a file that runs without Godot installed.

  1. Project → Export.
  2. Add… a preset (Windows Desktop, or HTML5/Web — see below).
  3. The first time, Godot asks for export templates — click to download them (needs internet, do this early!).
  4. Choose a folder, click Export Project.
  5. You get an .exe (Windows) the player double-clicks.

#Option C — export for the Web (HTML5) and put it on itch.io

Best for sharing a link with family after camp.

  1. In Export, add a Web preset, export → you get index.html + support files.
  2. Zip those files.
  3. Make a free itch.io account → Upload new project → set kind to HTML → upload the zip → check "This file will be played in the browser."
  4. Now anyone with the link can play it. 🎉

#Sharing your game

  • At the showcase: Option A (run from editor) or the exported build on the demo machine.
  • Take it home: copy the whole project folder to a USB / cloud drive, or upload to itch.io (Option C). The project folder is everything — keep it together.
⚠️Back up before you export

Copy your project folder somewhere safe first. Export settings rarely break a project, but the night before the showcase is no time to find out. See Sharing Files on a Team.

💡Hard deadline

Working build on the demo machine by 3:00 PM Friday (Day 5 - Polish and Showcase). Test it actually runs on that machine, not just yours.
