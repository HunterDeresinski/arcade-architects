GDScript is Godot's coding language. It looks a lot like Python. A script is attached to a node and gives it behavior. If you've used Pico-8 (Lua), the ideas are the same; the spelling is different.

❗Indentation matters

GDScript uses tabs to group code, like Python. Lines inside a function are indented one tab. Wrong indentation = error.

#Attaching a script

Select a node → click the Attach Script icon (scroll/page icon) in the Scene dock → Create. You get a file like player.gd.

#Variables — store a value

var speed = 400          # a number you can change
var score = 0
var player_name = "Fern" # text (a String)
var is_alive = true      # true/false (a bool)

Change speed and the whole feel of the game changes — variables are your dials.

#Constants and exported variables

const MAX_LIVES = 3        # never changes

@export var speed = 400    # shows up in the Inspector so you can tweak without code

@export is great for teammates: the Artist can change speed in the Inspector without touching code.

#The two functions you'll use most

func _ready():
	# runs ONCE when this node enters the game
	print("Game started!")

func _process(delta):
	# runs EVERY frame (about 60x per second)
	# 'delta' = seconds since the last frame; multiply movement by it
	pass

#If statements — make decisions

if score >= 10:
	print("You win!")
elif score > 0:
	print("Keep going")
else:
	print("Score is zero")

Comparisons: == equal, != not equal, > < >= <=. Combine with and / or / not.

#Functions — your own named actions

func add_points(amount):
	score += amount        # += means "add to"
	print("Score is now ", score)

Call it with add_points(10).

#Math shortcuts

score += 1   # add 1
speed -= 50  # subtract 50
lives = lives - 1

#Printing to debug

print("anything") shows in the Output panel (Godot Editor Tour). When something's wrong, sprinkle prints to see what your code is actually doing.

💡You don't need to memorize this

Keep this note open while you work. Copy a block, change the names, run it. That's real coding.
