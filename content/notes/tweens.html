The animation tool the rest of this reference assumes. Read it when you want anything to move, fade, pop, or slide.

A tween animates a property from one value to another over time. create_tween() shows up in six other notes in this reference — Collectables, Dash and Double Jump, Doors and Keys, Health and Lives, Juice and Game Feel, Moving Platforms — and this is the note that explains it.

If you learn one optional thing this week, learn this. It is the single highest ratio of "looks impressive" to "lines of code" in Godot.

#The one-liner

create_tween().tween_property($Sprite, "modulate:a", 0.0, 0.5)

"Fade the sprite to invisible over half a second." That's a complete, working animation.

#Reading the syntax

create_tween().tween_property(WHAT, "WHICH_PROPERTY", TO_VALUE, HOW_LONG)
PartMeans
create_tween()make a new tween that runs on this node
WHATthe node to animate — self, $Sprite, $UI/HealthBar
"WHICH_PROPERTY"the property name as text: "position", "scale", "rotation", "modulate"
TO_VALUEwhere it should end up
HOW_LONGseconds

The "property:sub" form reaches inside a value: "position:y" animates only the y, "modulate:a" animates only the alpha (transparency). Very handy.

#Sequences: one after another

Tweens are sequential by default — each step waits for the previous one.

func bump():
	var t = create_tween()
	t.tween_property($Sprite, "scale", Vector2(1.4, 0.7), 0.1)   # squash
	t.tween_property($Sprite, "scale", Vector2(0.9, 1.2), 0.1)   # stretch
	t.tween_property($Sprite, "scale", Vector2(1.0, 1.0), 0.1)   # settle

Three lines, and you have classic squash-and-stretch.

#Parallel: all at once

var t = create_tween().set_parallel()
t.tween_property(self, "scale", Vector2(1.6, 1.6), 0.25)
t.tween_property(self, "modulate:a", 0.0, 0.25)
t.tween_property(self, "position:y", position.y - 20, 0.25)

Grow, fade, and float up simultaneously — the coin pickup effect from Collectables.

#Easing: where the personality lives

The same movement feels completely different depending on the curve.

create_tween().tween_property($Menu, "position:x", 0, 0.4)\
	.set_trans(Tween.TRANS_BACK).set_ease(Tween.EASE_OUT)
TransitionFeels like
TRANS_LINEARrobotic, constant speed (the default — usually the worst choice)
TRANS_SINEgentle, natural. Good default for almost anything
TRANS_BACKovershoots and settles back. Menus and pop-ins
TRANS_ELASTICwobbles like jelly. Fun, easy to overuse
TRANS_BOUNCEbounces on landing
TRANS_EXPOvery slow start, very fast finish. Dramatic
EaseMeans
EASE_INslow start, fast end
EASE_OUTfast start, slow end — most natural for UI
EASE_IN_OUTslow at both ends
💡The two-word upgrade

Add .set_trans(Tween.TRANS_SINE).set_ease(Tween.EASE_OUT) to any tween you already have. It will immediately look more professional. This is most of what "polish" means.

#Other things a tween can do

var t = create_tween()
t.tween_property($Sprite, "modulate", Color.RED, 0.1)
t.tween_interval(0.5)                    # just wait
t.tween_callback(explode)                # call a function
t.tween_callback(queue_free)             # then delete this node
# animate a plain number, not a node property
create_tween().tween_method(set_score_display, old_score, new_score, 0.4)

func set_score_display(value):
	$UI/ScoreLabel.text = "Score: %d" % int(value)

That makes a score count up instead of snapping — a tiny touch players always notice.

#Looping

var t = create_tween().set_loops()        # forever
var t = create_tween().set_loops(3)       # three times

The idle bob on a coin (Collectables):

func _ready():
	var t = create_tween().set_loops()
	t.tween_property($Sprite, "position:y", -6.0, 0.6).as_relative().set_trans(Tween.TRANS_SINE)
	t.tween_property($Sprite, "position:y",  6.0, 0.6).as_relative().set_trans(Tween.TRANS_SINE)

as_relative() means "move by this much" instead of "move to this position."

#Waiting for one to finish

var t = create_tween()
t.tween_property(self, "modulate:a", 0.0, 0.3)
await t.finished
queue_free()

#Tween vs AnimationPlayer vs Timer

UseWhen
Tweenshort, code-driven, one property, made on the fly — hit flashes, pop-ins, UI slides
AnimationPlayerlonger, hand-keyframed, many properties at once, editable by an artist — walk cycles, cutscenes
Timeryou don't want to animate anything, you just want to wait

#Common problems

ProblemFix
"Property not found" errorThe property name must be a string and spelled exactly: "modulate:a", not modulate.a
Animation restarts and looks glitchyYou're creating a new tween every frame. Create it once, in a function you call once
Node errors after the tween endsIt got queue_free()d mid-tween. await t.finished before freeing, or use t.tween_callback(queue_free)
Nothing happensTweens don't run on a node that isn't in the scene tree yet — don't tween inside _init()
Two tweens fight over the same propertyvar t = create_tween() then t.kill() before starting a new one
