Sound is the cheapest way to make a game feel alive. One coin "ding" does more than an hour of art. Get free sounds from Asset Resources.

#The two player nodes

  • AudioStreamPlayer — non-positional sound. Use for music and UI sounds (most tiny games only need this).
  • AudioStreamPlayer2D — sound that gets quieter with distance. Usually overkill for a one-screen game.

#Add a sound effect

  1. Drag a .wav or .ogg file into your project (FileSystem dock).
  2. Add an AudioStreamPlayer node.
  3. In the Inspector, set its Stream to your sound file.
  4. Play it from code when something happens:
func _on_body_entered(body):
	$CoinSound.play()   # the AudioStreamPlayer child named CoinSound

#Background music (loops)

  1. Add an AudioStreamPlayer, set Stream to your music.
  2. Check Autoplay in the Inspector to start it on scene load, or start it in code:
func _ready():
	$Music.play()
  1. To loop: select the audio file in FileSystem → Import tab → check Loop → Reimport.

#Stop or change volume

$Music.stop()
$Music.volume_db = -10   # quieter (negative = softer, 0 = full)

#Make your own sound effects (free, fast, fun)

  • jsfxr or ChipTone — click a button, get a retro "pew/coin/jump" sound in seconds. Export .wav, drag into Godot. Links in Asset Resources.
💡Showcase polish

For Friday, aim for: one music loop + 2–3 sound effects (point, hit, win). That alone makes a game feel finished (Day 5 - Polish and Showcase).

⚠️Headphones / volume

12 games playing at once is chaos. Use headphones during work time, and keep showcase volume reasonable.
