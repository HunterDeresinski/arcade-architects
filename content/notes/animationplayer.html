The most artist-friendly node in Godot. Keyframe any property of any node on a timeline, with no code.

Keyframe any property of any node on a timeline, with no code. Collectables, Hazards, and Moving Platforms all offer it as the no-code option — this is how it works.

This is the most artist-friendly node in Godot. If your team has someone who thinks in pictures and timelines rather than code, hand them this note and a lot of your game gets built without them writing a line.

#What it can animate

Nearly everything: position, rotation, scale, modulate, visible, frame, a Label's text, a CollisionShape2D's disabled, an AudioStreamPlayer's playback. It can also call functions at a specific moment on the timeline.

#Setting one up

  1. Add an AnimationPlayer node as a child of the thing you're animating.
  2. The Animation panel opens at the bottom. Click Animation → New, name it (idle, attack, open).
  3. Set the duration (the number at the top right of the timeline, in seconds).
  4. Select the node you want to animate, move the playhead to a time, change a property in the Inspector, and click the key icon next to that property. That's a keyframe.
  5. Move the playhead, change the value, key it again. Godot fills in everything between.
💡Turn on the auto-key button

The key-shaped toggle in the Animation panel records a keyframe automatically whenever you change a property. It turns keyframing from four clicks into one.

#The two toggles you'll want

  • Loop (the ↻ icon next to the animation name) — plays forever. Use for idle, walk, a bobbing coin.
  • Autoplay on Load (the "A" icon) — starts by itself when the scene loads. Idle animations, ambient motion.

Together they make ambient animation genuinely zero-code.

#Playing from code

$AnimationPlayer.play("attack")
$AnimationPlayer.play("walk")
$AnimationPlayer.play_backwards("open")
$AnimationPlayer.stop()
$AnimationPlayer.speed_scale = 2.0                # double speed
$AnimationPlayer.current_animation                # what's playing right now
$AnimationPlayer.is_playing()

Wait for one to end:

$AnimationPlayer.play("attack")
await $AnimationPlayer.animation_finished
can_attack = true

Or connect the animation_finished signal in the editor.

#Call Method tracks (the powerful bit)

An animation can call your functions at exact moments on the timeline. This is how you sync a sword's damage window to the frame where the blade is actually out — see Melee Attacks.

  1. Add Track → Call Method Track, pick the node that owns the function.
  2. Right-click on the timeline at the moment you want → Insert Key → choose the method.
# animation calls these at exactly the right frames
func enable_hitbox():  $Hitbox.monitoring = true
func disable_hitbox(): $Hitbox.monitoring = false

The designer tunes attack timing by dragging keyframes, not by editing timer values. That's a genuinely better workflow.

There's also an Audio Track for playing a sound at an exact frame — footsteps landing on the right frame of a walk cycle.

#What people actually build with it

  • A door swinging open (Doors and Keys) — rotation + a sound
  • A moving platform (Moving Platforms) — key position at each end, loop it
  • A coin's idle bob (Collectables) — key position:y, loop, autoplay
  • A boss telegraph — wind-up, flash, attack, recover, all on one timeline
  • A title screen intro — logo drops in, buttons slide up, all keyframed
  • A death animation — sprite spins, fades, then a Call Method track fires queue_free()
  • A saw blade on a path — pairs with Path2D and PathFollow2D

#AnimationPlayer vs the alternatives

UseWhen
AnimatedSprite2Dflipping through sprite frames — a hand-drawn walk cycle
AnimationPlayermoving/rotating/fading nodes on a timeline; many properties at once; artist-editable
Tweensshort, one-off, code-driven — a hit flash, a menu slide

They combine happily: an AnimationPlayer track can drive which animation an AnimatedSprite2D is playing.

#AnimationTree — and why to skip it

Godot has an AnimationTree node for blending animations with state machines. It's powerful and it is not a five-day-camp tool — see State Machines. Plain play("name") calls are fine for everything you'll build this week.

Animation fights your movement codeBoth are setting position. Pick one owner per property
