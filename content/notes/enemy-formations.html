Space Invaders enemies: spawn a whole line of aliens at once and march them down toward the player. The partner note to Making Bullets (Example 1 is the ship that shoots these). Builds on Spawning and Timers.

#The big idea: move the parent, not the aliens

Don't give every alien its own movement script. Spawn them all as children of one Node2D, then move that. One script moves fifty aliens, and they stay in perfect formation for free.

Main
├── Player       ← the ship from Making Bullets, Example 1
└── Fleet        (Node2D)   ← script goes HERE; aliens spawn inside

#The alien scene

Alien           (Area2D)            Layer: mobs, Mask: player
├── Sprite      (AnimatedSprite2D)  ← 2-frame wiggle sells the invader look
└── Shape       (CollisionShape2D)

No script needed on the alien — the Fleet moves it, the bullet kills it. Optionally connect its body_entered to hurt the player on touch (body.take_damage(), see Hazards and Health and Lives). Save as alien.tscn.

⚠️Area2D aliens need the bullet's OTHER signal

The Making Bullets bullet connects body_entered — but an Area2D alien is not a body, so that signal never fires (Area2D → The four signals). In the Bullet scene, also connect area_entered:

func _on_area_entered(area):
	area.queue_free()   # kill the alien
	queue_free()        # remove the bullet

#Spawning a line

Script on the Fleet node. A for loop plus multiplication is the whole trick:

extends Node2D

@export var alien_scene: PackedScene   # drag alien.tscn here in the Inspector
@export var columns = 8
@export var spacing = 60               # pixels between aliens

func _ready():
	spawn_row(60)   # one row near the top

func spawn_row(y):
	var screen_width = get_viewport_rect().size.x
	var row_width = (columns - 1) * spacing
	var start_x = (screen_width - row_width) / 2   # centers the row

	for i in columns:
		var alien = alien_scene.instantiate()
		alien.position = Vector2(start_x + i * spacing, y)
		add_child(alien)
  • start_x + i * spacing — alien 0 at the left end, each next one spacing pixels over. That's the entire "line" mechanic.
  • start_x math — total row width is (columns - 1) * spacing (gaps, not aliens); subtracting from the screen width and halving centers it. Skip it and hardcode start_x = 80 if the math distracts.
  • Want a grid instead of one line? Wrap it in a second loop:
func spawn_grid(rows = 3):
	for r in rows:
		spawn_row(60 + r * 50)   # each row 50px lower

#Version A: the fleet marches down

Simplest — the whole formation descends. Add to the Fleet script:

@export var descend_speed = 20   # pixels per second — slow is scary

func _process(delta):
	position.y += descend_speed * delta

That's it — the parent moves, every alien inside moves with it.

Lose condition — an alien reached the bottom:

	# add inside _process, after the movement
	for alien in get_children():
		if alien.global_position.y > 600:   # your "they got through" line
			get_tree().change_scene_to_file("res://game_over.tscn")  # see Scene Switching
			break

Endless waves (Spawning and Timers) — add a Timer child (Wait Time 4, Autostart ✓, repeat), connect timeout:

func _on_timer_timeout():
	spawn_row(0)   # new row appears at the top as the fleet descends

Win condition — every alien in the fleet is dead:

	# also inside _process
	if get_child_count() == 0:
		get_tree().change_scene_to_file("res://win_screen.tscn")

(If the wave Timer is a child of Fleet, count it out: get_child_count() == 1. Cleaner: keep the Timer on Main instead.)

#Version B: the classic Space Invaders march

Side to side, and drop down + reverse + speed up every time the formation touches a screen edge. Replace Version A's _process:

@export var speed = 60      # sideways speed
@export var drop = 24       # pixels down per edge-hit

var direction = 1           # 1 = right, -1 = left

func _process(delta):
	position.x += speed * direction * delta

	var screen_width = get_viewport_rect().size.x
	for alien in get_children():
		var x = alien.global_position.x
		if (direction == 1 and x > screen_width - 40) or (direction == -1 and x < 40):
			direction *= -1              # turn around
			position.y += drop           # step down
			speed += 8                   # the famous speed-up
			break
  • The edge check looks at alien positions, not the Fleet's — as you shoot the outer columns, the formation gets narrower and marches further before turning, exactly like the arcade original.
  • break — one alien touching the edge is enough; without it, ten aliens each trigger the turn on the same frame and the fleet nosedives.
  • speed += 8 — fewer aliens = faster march happens naturally in real Space Invaders; this simpler version speeds up per drop instead. Delete the line for a fixed pace.
  • Same lose/win checks as Version A still apply.
💡Tuning the panic

Three knobs: speed (how fast the wall closes in), drop (how much each edge-hit costs the player), and in Version A descend_speed. Small drop + rising speed = slow dread. Big drop = sudden panic. Playtest both (Playtesting).
