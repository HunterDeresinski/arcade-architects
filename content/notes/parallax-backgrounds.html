🏠 Curriculum Map · 🧰 Extras Index · 📁 Tier 2 — Showcase Payoff

Difficulty: ⭐ easy · Payoff: ⭐⭐⭐ huge · Time: 10 minutes

Backgrounds that scroll slower than the foreground, creating an illusion of depth. Distant mountains drift; nearby bushes rush past. It costs almost nothing and it's the closest thing to a cheat code for making a game look finished.

#The idea

Look out a car window. Fence posts blur past. Mountains barely move. Your brain reads that speed difference as distance. Parallax fakes it in 2D.

#Setup in Godot 4.3+

Use Parallax2D — one node per layer, no wrapper needed.

  1. Add a Parallax2D node to your scene.
  2. Add a Sprite2D child and drop your background art in.
  3. Set Parallax2D's Scroll Scale — Vector2(0.2, 0.2) means "move at 20% of camera speed."
  4. Repeat for each layer.
Main
├── Sky          (Parallax2D)  Scroll Scale: (0.1, 0.1)   ← barely moves
│   └── Sprite
├── Mountains    (Parallax2D)  Scroll Scale: (0.3, 0.3)
│   └── Sprite
├── Trees        (Parallax2D)  Scroll Scale: (0.6, 0.6)
│   └── Sprite
├── TileMapLayer                                          ← the actual level (1.0)
└── Player
    └── Camera2D

Rule: farther away = smaller Scroll Scale. 0.0 is painted on the screen and never moves; 1.0 moves exactly with the world.

#Making it repeat forever

Set Repeat Size to your image's width (e.g. Vector2(1920, 0) for a 1920px-wide image) and Godot tiles it endlessly as you scroll. Set only the x for horizontal-scrolling games.

For this to look seamless the art must be tileable — the right edge has to line up with the left. Most free parallax packs on itch.io already are; look for "seamless" or "loopable" in the description.

#Older Godot 4 (ParallaxBackground)

If you're on 4.0–4.2, the older pair still works:

ParallaxBackground
├── ParallaxLayer   Motion Scale: (0.2, 0.2)  Motion Mirroring: (1920, 0)
│   └── Sprite2D
└── ParallaxLayer   Motion Scale: (0.5, 0.5)
    └── Sprite2D

Same concepts, different property names: Motion Scale = Scroll Scale, Motion Mirroring = Repeat Size.

#It needs a camera

Parallax reacts to a moving Camera2D. In a single-screen game (Pong, Space Invaders, Dodge the Creeps) nothing scrolls, so nothing parallaxes. For those, scroll the background yourself:

extends Parallax2D

@export var auto_speed = Vector2(-40, 0)   # negative = drifts left

func _process(delta):
	scroll_offset += auto_speed * delta

This is arguably better than real parallax for an arcade game. An endlessly drifting starfield behind a fixed-screen shooter looks fantastic and works with zero camera setup.

#Choosing layers

Three layers is the sweet spot. More is rarely worth the effort.

LayerScroll ScaleContent
Sky / gradient0.0 – 0.1flat colour, stars, sun

Near0.5 – 0.8bushes, fences, foreground grass
World1.0your TileMapLayer
💡Fade the distance

Set far layers' modulate to a slightly washed-out tint (Color(0.8, 0.85, 1.0)). Real distance desaturates and blues things — this is called atmospheric perspective, and it sells depth even harder than the motion does.

#Common problems

ProblemFix
Background doesn't move at allNo Camera2D, or the camera isn't moving. Use the auto-scroll script instead
Visible seam when it repeatsArt isn't tileable, or Repeat Size doesn't exactly match the image width
Background covers the levelSet the Parallax2D's z_index to a negative number
Layers move the wrong relative amountsFar layers need smaller scroll scales — it's easy to get backwards
Repeat looks stretchedDon't scale the sprite; set Repeat Size to the scaled width if you must
