Difficulty: ⭐ easy · Payoff: ⭐⭐ solid · Time: 10 minutes

Tells you when something enters or leaves the screen. Small node, and it quietly solves the most common performance bug in a camp game: bullets that never die.

#The problem it solves

Every bullet you fire in Making Bullets flies off screen and keeps existing forever. Fire for two minutes and you have a thousand invisible bullets, each running _physics_process every frame. The game slows down and nobody can see why.

#Setup

Add a VisibleOnScreenNotifier2D as a child. Size its rectangle in the viewport to roughly cover the sprite. Then connect one of two signals:

  • screen_entered — became visible
  • screen_exited — left the view
func _on_visible_on_screen_notifier_2d_screen_exited():
	queue_free()

One node, one signal, one line. Add it to your bullet scene and the problem is gone permanently.

#What people actually use it for

Cleaning up bullets — as above. Do this on every bullet scene (Making Bullets).

Removing off-screen enemies — a mob that drifted away and is never coming back (Spawning and Timers):

func _on_screen_exited():
	queue_free()
⚠️Don't free things that start off screen

An enemy spawned outside the view fires screen_exited immediately — or never fires screen_entered — and deletes itself before it ever arrives. Guard it:

var has_been_seen = false

func _on_screen_entered():
	has_been_seen = true

func _on_screen_exited():
	if has_been_seen:
		queue_free()

Waking enemies only when visible — a big level with fifty enemies runs badly if all fifty are thinking at once:

func _on_screen_entered():
	set_physics_process(true)

func _on_screen_exited():
	set_physics_process(false)

This is the classic optimization for a large TileMapLayer level. Combine with Enemy States so an enemy resumes patrolling where it left off.

Keeping the player on screen — flip an enemy or wrap a ship at the boundary (Screen Wrap and Thrust).

Triggering a boss or a checkpoint when the player scrolls it into view — a nicer trigger than an Area2D because it reacts to the camera, not to touch.

Pausing off-screen Particles to save frames:

func _on_screen_exited():
	$Particles.emitting = false

#VisibleOnScreenEnabler2D — the no-code version

There's a sibling node, VisibleOnScreenEnabler2D, that automatically switches its parent's process mode on and off based on visibility. Set Enable Node Path to the node you want managed, and you get the wake-when-visible behaviour with zero script.

Use the Enabler when you just want the optimization; use the Notifier when you want to do something specific.

#Common problems

ProblemFix
Signal never firesThe notifier's rectangle is tiny or zero-sized — size it in the viewport
Enemies vanish before appearingThey spawned off screen. Use the has_been_seen guard
Bullets still pile upSignal connected on the wrong node, or connected to nothing
Works in the editor, not in gameRectangle is positioned away from the sprite — check its offset
"Screen" seems wrongIt means the camera's view, not the window. A zoomed-out Camera2D sees more
