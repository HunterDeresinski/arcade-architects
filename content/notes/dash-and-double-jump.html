Two abilities that make a platformer feel good to control. Both are short, both bolt onto the script in Platformer Physics, and both are the kind of thing playtesters notice immediately. Uses Timer and CharacterBody2D.

💡Add these after your game works

These are feel upgrades, not features. Get the level, the enemies, and the win condition working first — then spend twenty minutes here and watch the game get twice as fun.

#Double Jump

#The idea

You already have is_on_floor() gating your jump. A double jump just means counting jumps instead of asking about the floor.

extends CharacterBody2D

@export var speed = 300.0
@export var jump_velocity = -400.0
@export var max_jumps = 2          # 2 = double jump. 3 = triple. Try it.

var jumps_left = 0

func _physics_process(delta):
	if not is_on_floor():
		velocity += get_gravity() * delta
	else:
		jumps_left = max_jumps         # touching ground refills your jumps

	if Input.is_action_just_pressed("jump") and jumps_left > 0:
		velocity.y = jump_velocity
		jumps_left -= 1
		if jumps_left < max_jumps - 1:
			double_jump_effect()        # only on the airborne ones

	var direction = Input.get_axis("move_left", "move_right")
	velocity.x = direction * speed if direction else move_toward(velocity.x, 0, speed)

	move_and_slide()

is_action_just_pressed (not is_action_pressed) is essential — otherwise holding the button burns every jump in one frame.

#Make the second jump readable

The air jump should look different from the ground jump, or players won't realize they have one:

func double_jump_effect():
	$JumpSound.pitch_scale = 1.3        # higher pitch for the air jump
	$JumpSound.play()
	var t = create_tween()
	t.tween_property($Sprite, "scale", Vector2(0.7, 1.3), 0.08)   # stretch up
	t.tween_property($Sprite, "scale", Vector2(1, 1), 0.12)

#Coyote time (the one every platformer needs)

Players constantly press jump a frame or two after walking off a ledge, and a game that refuses feels stiff and unfair. Give them a grace window.

Add a CoyoteTimer (Timer, One Shot on, Wait Time 0.12):

var was_on_floor = false

func _physics_process(delta):
	var on_floor = is_on_floor()
	if was_on_floor and not on_floor and velocity.y >= 0:
		$CoyoteTimer.start()          # just walked off a ledge
	was_on_floor = on_floor

	var can_ground_jump = on_floor or not $CoyoteTimer.is_stopped()
	if Input.is_action_just_pressed("jump"):
		if can_ground_jump:
			velocity.y = jump_velocity
			jumps_left = max_jumps - 1
			$CoyoteTimer.stop()
		elif jumps_left > 0:
			velocity.y = jump_velocity
			jumps_left -= 1
			double_jump_effect()

Nobody will ever say "I love your coyote time." They'll say the controls feel good. That's the point.

#Variable jump height

Tap for a short hop, hold for a full jump. Two lines:

if Input.is_action_just_released("jump") and velocity.y < 0:
	velocity.y *= 0.4    # let go early, cut the rise short

Coyote time and variable jump height together are the two highest-value additions to any platformer in this camp.

#Dash

#The idea

A dash is a short burst at high speed in a fixed direction, with a cooldown. Three pieces of state: are we dashing, which way, and can we dash again yet.

Add two Timer nodes, both One Shot on, Autostart off:

  • DashTimer — Wait Time 0.15 (how long the dash lasts)
  • DashCooldown — Wait Time 0.6 (how long until you can dash again)
@export var dash_speed = 900.0

var is_dashing = false
var dash_direction = Vector2.ZERO

func _physics_process(delta):
	if is_dashing:
		velocity = dash_direction * dash_speed
		move_and_slide()
		return                    # skip gravity and normal input entirely

	# ---- normal movement here (gravity, walk, jump) ----

	if Input.is_action_just_pressed("dash") and $DashCooldown.is_stopped():
		start_dash()

	move_and_slide()

func start_dash():
	var input_dir = Input.get_vector("move_left", "move_right", "move_up", "move_down")
	if input_dir == Vector2.ZERO:
		input_dir = Vector2.RIGHT * (-1 if $Sprite.flip_h else 1)   # dash where you face
	dash_direction = input_dir.normalized()
	is_dashing = true
	velocity = dash_direction * dash_speed

	$DashTimer.start()
	$DashCooldown.start()
	$DashSound.play()
	$Ghosts.emitting = true          # optional trail, see below

func _on_dash_timer_timeout():
	is_dashing = false
	velocity *= 0.3                  # bleed off speed so you don't rocket away
	$Ghosts.emitting = false

Add dash to Project Settings → Input Map (Shift is the convention).

The is_stopped() cooldown check is the same Timer pattern as a weapon's fire rate in Making Bullets — once students have it, they reuse it everywhere.

#Invincible dash

Let the player dash through enemies. Wire it to the hurtbox from Health and Lives:

func start_dash():
	# ...as above...
	invincible = true

func _on_dash_timer_timeout():
	is_dashing = false
	invincible = false

This changes the dash from a movement tool into a defensive skill, and instantly makes combat more interesting. Great design conversation: the same mechanic can be about getting somewhere or about surviving, depending on one flag.

#Air dash (one per jump)

var can_air_dash = true

# in _physics_process, when on the floor:
can_air_dash = true

if Input.is_action_just_pressed("dash") and $DashCooldown.is_stopped():
	if is_on_floor() or can_air_dash:
		if not is_on_floor():
			can_air_dash = false
		start_dash()

Air dash plus double jump gives a platformer a real movement vocabulary — suddenly there are multiple ways to cross a gap, and level design gets more interesting.

#The ghost trail

The cheapest way to make a dash look expensive:

func spawn_ghost():
	var ghost = Sprite2D.new()
	ghost.texture = $Sprite.texture
	ghost.global_position = global_position
	ghost.flip_h = $Sprite.flip_h
	ghost.modulate = Color(0.6, 0.8, 1.0, 0.6)
	ghost.z_index = z_index - 1
	get_tree().current_scene.add_child(ghost)
	var t = ghost.create_tween()
	t.tween_property(ghost, "modulate:a", 0.0, 0.3)
	t.tween_callback(ghost.queue_free)

Call it every couple of frames while dashing:

if is_dashing and Engine.get_physics_frames() % 2 == 0:
	spawn_ghost()

Also worth adding: a short Camera2D shake and a brief slow-motion via Engine.time_scale (Juice and Game Feel).

#A cooldown the player can see

func _process(_delta):
	$UI/DashBar.value = 1.0 - ($DashCooldown.time_left / $DashCooldown.wait_time)

A ProgressBar under a CanvasLayer (Label and CanvasLayer). Players will use an ability far more often when they can see it's ready.

#Common problems

ProblemFix
Dash never stopsDashTimer's timeout isn't connected, or One Shot is off
Dashes forever while holding the keyUse is_action_just_pressed, not is_action_pressed
Dash goes nowhere when standing stillAdd the fallback direction based on facing
Player rockets off after dashingAdd velocity *= 0.3 on dash end
Double jump gives infinite jumpsjumps_left is being reset somewhere every frame — check it's only reset when is_on_floor()
Dash phases through wallsmove_and_slide() handles it; if it still tunnels, lower dash_speed or thicken walls
