Difficulty: ⭐⭐ moderate · Payoff: ⭐⭐⭐ high · Time: 20 minutes

Explosions, sparks, dust, smoke, magic trails, rain. Juice and Game Feel uses a particle burst for a death effect — this is the full node.

#GPUParticles2D vs CPUParticles2D

NodeUse when
GPUParticles2Ddefault choice. Thousands of particles, runs on the graphics card
CPUParticles2Dold/weak hardware, or a laptop where GPU particles render as black squares

Same properties, same ideas. If particles look broken on a school laptop, right-click the node → Convert to CPUParticles2D. Keep this in your back pocket for Friday.

#Setting one up

  1. Add a GPUParticles2D node.
  2. Inspector → Process Material → <empty> → New ParticleProcessMaterial. (Nothing renders until you do this.)
  3. Texture → drag in a small image — a white dot, a star, a puff. A 16×16 soft circle covers most needs.
  4. Amount → how many particles exist at once.
  5. Press play in the viewport to preview.
⚠️Two empty slots = nothing visible

No Process Material, or no Texture, means invisible particles. Godot doesn't warn you. Check both first.

#The properties that matter

Under Process Material:

PropertyDoes
Directionwhich way they head. (0, -1) = up
Spreadcone angle in degrees. 180 = every direction
Initial Velocity Min/Maxspeed range. Set them apart for natural variety
Gravity(0, 980) falls, (0, -100) floats up like smoke, (0,0) drifts
Scale Min/Maxparticle size
Colortint. Use a Gradient to fade out over life
Angular Velocityspin
Dampingslows particles down over time

On the node itself:

PropertyDoes
Amountparticle count
Lifetimeseconds each particle lives
One Shot✅ for a burst, ❌ for a continuous stream
Explosiveness0 = steady trickle, 1 = all at once. Set to 1 for explosions
Emittingon/off switch — the thing you toggle from code
Local Coords❌ so particles stay behind when the emitter moves (correct for trails)
💡The single most important setting

Explosiveness = 1 plus One Shot = on is the difference between "an explosion" and "a sad sprinkle." Almost every burst effect wants both.

#Firing one from code

A continuous effect (dust while running, a rocket flame):

$DustParticles.emitting = velocity.length() > 10 and is_on_floor()

A one-shot burst (One Shot ✅, Explosiveness 1):

$HitParticles.restart()      # restart() re-fires it; emitting = true only works once

A burst that outlives the thing that died — the important pattern. A particle child of a node you queue_free() disappears instantly, so spawn it into the scene instead:

const ExplosionScene = preload("res://explosion.tscn")

func die():
	var boom = ExplosionScene.instantiate()
	get_tree().current_scene.add_child(boom)
	boom.global_position = global_position
	boom.emitting = true
	queue_free()

Make explosion.tscn a GPUParticles2D with One Shot on, and give it this script so it cleans itself up:

extends GPUParticles2D

func _ready():
	emitting = true
	await get_tree().create_timer(lifetime + 0.1).timeout
	queue_free()

#Emission shapes

Process Material → Emission Shape controls where particles spawn: Point (default), Sphere (a circular puff), Box (rain, a wall of fire), or Points (an exact custom pattern). Sphere with a small radius makes an explosion read much better than a single point.

#Where to use them

  • Enemy death (Health and Lives)
  • Coin collection (Collectables)
  • Landing from a jump, running dust (Platformer Physics)
  • Dash trail (Dash and Double Jump) — though the ghost-sprite trick there looks better for a character
  • Bullet impacts (Making Bullets)
  • Lava bubbles, sparks off spikes (Hazards)
  • Ambient snow or falling leaves — instant atmosphere for a whole level

#Common problems

ProblemFix
Nothing visibleMissing Process Material or Texture
Black squaresConvert to CPUParticles2D — a driver issue on old laptops
Fires only once, never againUse restart(), not emitting = true
Particles vanish when the enemy diesSpawn the effect as a separate scene, don't parent it to the dying node
Trail follows the player in a clumpUncheck Local Coords
Explosion looks like a fountainExplosiveness is 0 — set it to 1
Game slows to a crawlAmount is in the thousands. 20–50 is plenty for a burst
