A ball that flies around and bounces off walls — Pong, Breakout, Arkanoid, and any game with a projectile that ricochets. Built on CharacterBody2D and move_and_collide().

#Why not just use a RigidBody2D?

You can. Set Bounce to 1.0, Gravity Scale to 0, Linear Damp to 0, kick it once, and the engine does it (RigidBody2D and StaticBody2D).

But you'll fight it. Pong needs the ball to keep a constant speed forever, to speed up over time, and to change angle based on where it hit the paddle. A RigidBody2D bleeds energy, gets stuck in horizontal loops, and won't let you set those rules. Twelve lines of your own code gives you total control.

Rule of thumb: physics ball for a toy, coded ball for a game.

#The ball scene

Scene → New Scene → Other Node → CharacterBody2D, name it Ball, save as ball.tscn.

Ball            (CharacterBody2D)   Layer: obstacles, Mask: obstacles
├── Sprite       (Sprite2D)
└── Shape        (CollisionShape2D)  ← CircleShape2D

Use a circle. A rectangle ball catches on corners and produces bounces that look wrong.

#The core script

extends CharacterBody2D

@export var speed = 400.0
@export var max_speed = 900.0
@export var speedup_per_hit = 15.0

func _ready():
	launch()

func launch():
	# random angle, but never too vertical (a near-vertical serve is unplayable)
	var angle = randf_range(-PI / 4, PI / 4)
	if randi() % 2 == 0:
		angle += PI            # half the time, serve the other way
	velocity = Vector2.RIGHT.rotated(angle) * speed

func _physics_process(delta):
	var collision = move_and_collide(velocity * delta)
	if collision:
		velocity = velocity.bounce(collision.get_normal())
		speed = min(speed + speedup_per_hit, max_speed)
		velocity = velocity.normalized() * speed
		$HitSound.play()

That's the whole mechanic. The important bits:

  • move_and_collide(), not move_and_slide(). Slide is for characters — it slides along walls, which is the exact opposite of bouncing. move_and_collide() stops at the impact and hands you the collision.
  • velocity.bounce(normal) does the reflection math for you. The normal is the arrow pointing straight out of the surface you hit; bounce() mirrors your velocity around it. This is the one line people expect to be hard.
  • Re-normalizing to speed every bounce is what keeps a constant, arcade-feeling pace. Without it the ball slowly drifts faster or slower.

Walls are plain StaticBody2Ds on layer obstacles (RigidBody2D and StaticBody2D), or a TileMapLayer with collision.

#Pong: paddles and English

The magic of Pong isn't the bounce — it's that where the ball hits the paddle changes the angle. That's what turns it from a physics demo into a game with skill.

The paddle is a CharacterBody2D on layer obstacles:

extends CharacterBody2D

@export var speed = 500.0
@export var up_action = "p1_up"
@export var down_action = "p1_down"

func _physics_process(_delta):
	var dir = Input.get_axis(up_action, down_action)
	velocity = Vector2(0, dir * speed)
	move_and_slide()

@export on the action names means one paddle scene serves both players — drag in two instances and set p1_up/p1_down on one and p2_up/p2_down on the other in the Inspector. Add all four to Project Settings → Input Map.

Now replace the ball's bounce block to handle paddles specially:

func _physics_process(delta):
	var collision = move_and_collide(velocity * delta)
	if not collision:
		return

	var hit = collision.get_collider()
	if hit.is_in_group("paddles"):
		# where on the paddle did we land? -1 = top edge, 0 = middle, 1 = bottom
		var paddle_height = hit.get_node("Shape").shape.size.y
		var offset = (global_position.y - hit.global_position.y) / (paddle_height / 2.0)
		offset = clamp(offset, -1.0, 1.0)

		var bounce_angle = offset * deg_to_rad(60)      # up to 60 degrees
		var direction = -1.0 if velocity.x > 0 else 1.0 # send it back the other way
		velocity = Vector2(cos(bounce_angle) * direction, sin(bounce_angle))
	else:
		velocity = velocity.bounce(collision.get_normal())

	speed = min(speed + speedup_per_hit, max_speed)
	velocity = velocity.normalized() * speed
	$HitSound.play()

Put both paddles in a group called paddles (Node dock → Groups). Hit the paddle's center and the ball goes back flat; hit the edge and it fires off at a steep angle. That one rule is the entire game of Pong.

#Scoring: goal zones

An Area2D behind each paddle, stretched to cover the whole side:

extends Area2D

@export var scores_for_player = 1

func _on_body_entered(body):
	if body.is_in_group("ball"):
		get_parent().add_score(scores_for_player)
		body.reset()

And in the ball:

func reset():
	global_position = get_viewport_rect().size / 2
	velocity = Vector2.ZERO
	speed = 400.0
	await get_tree().create_timer(1.0).timeout   # a beat before the serve
	launch()

Display the score with Label and CanvasLayer.

#Breakout: bricks that break

Same ball, different targets. A brick is a StaticBody2D on layer obstacles with a script:

extends StaticBody2D

@export var points = 10

func destroy():
	get_tree().call_group("game", "add_score", points)
	queue_free()

In the ball's collision handler:

if hit.has_method("destroy"):
	hit.destroy()

has_method() is a nice trick — the ball doesn't need to know what a brick is, only that it knows how to be destroyed. Walls don't have destroy(), so they just bounce.

Lay out a grid of bricks from code so you're not dragging fifty by hand:

const BrickScene = preload("res://brick.tscn")

func build_wall():
	for row in 5:
		for col in 10:
			var b = BrickScene.instantiate()
			b.position = Vector2(80 + col * 72, 80 + row * 32)
			b.points = (5 - row) * 10       # top rows worth more
			$Bricks.add_child(b)

$Bricks is a plain Node2D container. Win when $Bricks.get_child_count() == 0.

#Common problems

ProblemFix
Ball sticks to a wall and vibratesYou used move_and_slide(). Use move_and_collide().
Ball tunnels straight through a wall at high speedCap max_speed, thicken the walls, or turn on the ball's Continuous CD in the Inspector
Ball gets stuck bouncing perfectly horizontally, foreverAfter bouncing, force a minimum vertical component (below)
Ball speeds up until it's invisibleYou forgot min(..., max_speed)
Bounces look wrong / catch on cornersUse a CircleShape2D, not a rectangle

The anti-horizontal fix, worth adding to any Pong:

if abs(velocity.y) < 60:
	velocity.y = 60 * sign(velocity.y) if velocity.y != 0 else 60
	velocity = velocity.normalized() * speed
