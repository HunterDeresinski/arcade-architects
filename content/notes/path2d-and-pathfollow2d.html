Difficulty: ⭐⭐ moderate · Payoff: ⭐⭐ solid · Time: 20 minutes

Draw a curve in the editor, and make something travel along it. Enemies that swoop in arcs, patrolling guards on a route, a saw blade circling a room, spawn points around the screen edge.

If you've done Day 1, you've already used one — Dodge the Creeps spawns mobs using a Path2D around the screen border.

#The two nodes

  • Path2D — holds the curve you draw. Does nothing by itself.
  • PathFollow2D — a child of Path2D. Anything parented to it gets dragged along the curve.
EnemyPath          (Path2D)          ← draw the curve here
└── Follow          (PathFollow2D)    ← script goes here
    └── Enemy       (your scene)      ← rides along

#Drawing a curve

  1. Add a Path2D node.
  2. In the 2D toolbar, click the ✏️ pencil ("Add Point").
  3. Click in the viewport to place points.
  4. Drag while placing to create curve handles instead of sharp corners.
  5. Existing point: drag to move, right-click to delete. Press Esc to leave draw mode.

Click the Close Curve button in the toolbar for a loop (a circling saw, a racetrack).

#Moving along it

extends PathFollow2D

@export var speed = 200.0

func _physics_process(delta):
	progress += speed * delta
  • progress — how far along in pixels.
  • progress_ratio — the same thing from 0.0 to 1.0. Easier for tweening.

Two Inspector checkboxes matter:

  • Loop — wraps back to the start at the end. On by default.
  • Rotates — the follower turns to face along the curve. Great for a plane or a car; turn it off for something that should stay upright.

Tween along it instead (Tweens) for a swoop with easing:

create_tween().tween_property(self, "progress_ratio", 1.0, 3.0)\
	.set_trans(Tween.TRANS_SINE)

#What people actually use it for

Swooping enemies (Galaga). The signature move of the genre — enemies fly in along an arc, then take formation. Combine with Enemy Formations:

extends PathFollow2D

func _ready():
	var t = create_tween()
	t.tween_property(self, "progress_ratio", 1.0, 2.5).set_trans(Tween.TRANS_SINE)
	await t.finished
	# hand the enemy over to the formation
	var enemy = $Enemy
	var pos = enemy.global_position
	remove_child(enemy)
	get_tree().current_scene.get_node("Fleet").add_child(enemy)
	enemy.global_position = pos
	queue_free()

Spawning around the screen edge — the Day 1 pattern:

$SpawnPath/SpawnLocation.progress_ratio = randf()
mob.global_position = $SpawnPath/SpawnLocation.global_position

One random number gives you a random point anywhere on the border. Much tidier than four if branches for four edges.

A patrolling guard on a real route — more expressive than the two-marker version in Patrol Enemies when the route has corners.

A saw blade circling a room — closed curve, Rotates on, constant speed. Pairs with Hazards.

A moving platform on a curve — parent an AnimatableBody2D to the PathFollow2D (Moving Platforms).

A camera dolly for a title screen — put a Camera2D on a PathFollow2D and slowly sweep across your level behind the menu.

#Back-and-forth instead of looping

Uncheck Loop, then:

var direction = 1

func _physics_process(delta):
	progress += speed * delta * direction
	if progress_ratio >= 1.0 or progress_ratio <= 0.0:
		direction *= -1

#Common problems

ProblemFix
Nothing movesScript is on the Path2D instead of the PathFollow2D
Object spins wildly at cornersUncheck Rotates
Jumps back to the start abruptlyLoop is on and the curve isn't closed — close it, or use back-and-forth
Enemy leaves the path but keeps getting draggedReparent it, as in the swoop example
Path is invisible in gameCorrect — Path2D is editor-only, like Marker2D
Speed varies around curvesPath2D uses even pixel spacing, so this is usually a tight-corner artifact. Add more points
