A node that counts down and then fires a signal. It's how anything in your game happens later or repeatedly — spawning, cooldowns, invincibility, "you win after 30 seconds."

#The three Inspector settings that matter

PropertyWhat it does
Wait Timeseconds to count down
Autostartstarts by itself when the scene loads
One Shoton = fires once and stops. off = repeats forever

Then connect the timeout signal to a function (Signals).

#Pattern 1: repeat forever

Wait Time 1.0, Autostart on, One Shot off.

func _on_spawn_timer_timeout():
	spawn_enemy()   # runs every 1 second, forever

This is the backbone of Spawning and Timers.

#Pattern 2: do something once, later

Autostart off, One Shot on. Start it from code:

func game_over():
	$RestartTimer.start()   # uses Wait Time from the Inspector

func _on_restart_timer_timeout():
	get_tree().reload_current_scene()

start() also accepts an override: $Timer.start(2.5) counts 2.5 seconds regardless of Wait Time.

#Pattern 3: a cooldown (can I shoot yet?)

The most useful Timer pattern in the whole reference. One Shot on, Autostart off.

func _process(_delta):
	if Input.is_action_pressed("shoot") and $ShootCooldown.is_stopped():
		shoot()
		$ShootCooldown.start()

is_stopped() returns true when the timer isn't running — so "is the cooldown over?" Change Wait Time to change fire rate. Same shape as the dash cooldown in Dash and Double Jump and the i-frames in Health and Lives.

#Useful methods

$Timer.start()          # begin (or restart from the top)
$Timer.stop()           # cancel; timeout will NOT fire
$Timer.is_stopped()     # true if not currently running
$Timer.paused = true    # freeze without cancelling
$Timer.time_left        # seconds remaining -- great for a countdown Label
$Timer.wait_time = 0.5  # change the duration from code

A countdown display, using Label and CanvasLayer:

func _process(_delta):
	$UI/TimeLabel.text = "Time: " + str(int($GameTimer.time_left))

#The one-line version: await

For a quick pause you don't want a whole node for:

func flash():
	modulate = Color.RED
	await get_tree().create_timer(0.2).timeout
	modulate = Color.WHITE

await pauses just this function for 0.2 seconds while the rest of the game keeps running. Perfect for hit flashes and short delays. Use a real Timer node when you need to check, restart, or cancel it — use await for fire-and-forget.

⚠️A gotcha with await

If the node gets queue_free()d during the wait, the code after await runs on a dead node and errors. Guard it: if not is_instance_valid(self): return.

#Making the game get harder

func _on_difficulty_timer_timeout():
	$SpawnTimer.wait_time = max(0.2, $SpawnTimer.wait_time - 0.1)

A second Timer that speeds up the first one. max() stops it becoming impossible.
