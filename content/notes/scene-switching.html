How to move between screens: Title → Game → Game Over → restart. This is what makes a project feel like a real, finished game.

#The three screens of a tiny game

TitleScreen.tscn   ← name, "Press Start"
Game.tscn          ← the actual game
GameOver.tscn      ← score + "Play Again"  (optional; can reuse Title)

Each is its own scene (Scenes and Nodes).

#Switch to another scene

func start_game():
	get_tree().change_scene_to_file("res://Game.tscn")

res:// means "from the project root." The path must match the file in the FileSystem dock exactly.

#A title screen with a Start button

On TitleScreen.tscn, add a Button, connect its pressed signal (Signals):

func _on_start_button_pressed():
	get_tree().change_scene_to_file("res://Game.tscn")

Or start on any key (good for a one-button game):

func _process(delta):
	if Input.is_action_just_pressed("ui_accept"):
		get_tree().change_scene_to_file("res://Game.tscn")

#Restart the current game

Simplest restart — reload the scene you're in:

func _on_retry_pressed():
	get_tree().reload_current_scene()

#Multiple levels: swap the tilemap, keep everything else

For games where the "levels" are just different tilemaps — level_1.tscn, level_2.tscn, each a painted TileMapLayer — and the start and exit are in the same place every level. The player touches the exit, the old tilemap is swapped for the next one, and the player teleports back to the start.

Because the player never gets destroyed, score, lives, and power-ups carry over automatically — no autoload needed.

The level scenes: each is a scene whose root is a TileMapLayer (TileMapLayer) with the level painted on it. Nothing else in them — no player, no exit. Design rule: every level's path must start and end at the same two spots.

The Main scene owns everything permanent:

Main             (Node2D)      ← script below goes here
├── Player                     ← never destroyed, never re-placed
├── StartPoint   (Marker2D)    ← same start spot, every level
├── Exit         (Area2D)      Layer: (none), Mask: player
│   ├── Sprite                 ← door / portal / flag art
│   └── Shape    (CollisionShape2D)
└── LevelHolder  (Node2D)      ← the current tilemap lives here

Script on Main — connect the Exit's body_entered signal (Signals) to the Main node (in the connect dialog, pick Main instead of Exit):

extends Node2D

@export var levels: Array[PackedScene]   # drag level_1, level_2... here IN ORDER
var current = 0

func _ready():
	load_level(0)

func load_level(index):
	# throw out the old tilemap
	for child in $LevelHolder.get_children():
		child.queue_free()
	# bring in the new one
	var level = levels[index].instantiate()
	$LevelHolder.add_child(level)
	# put the player at the start
	$Player.global_position = $StartPoint.global_position
	$Player.velocity = Vector2.ZERO

func _on_exit_body_entered(body):
	next_level.call_deferred()

func next_level():
	current += 1
	if current >= levels.size():
		get_tree().change_scene_to_file("res://win_screen.tscn")  # beat them all!
	else:
		load_level(current)
  • @export var levels: Array[PackedScene] — in the Inspector, set the array size and drag each level's .tscn into a slot. The array order IS the level order — rearranging your game is drag-and-drop, no code.
  • $Player.velocity = Vector2.ZERO — without it, a player who ran into the exit at full speed keeps that momentum into the next level.
  • call_deferred() — swapping physics objects (the tilemap) during a collision callback makes Godot complain ("flushing queries" error). Deferring waits for the physics step to finish. Needed any time body_entered triggers scene surgery.
  • Mask: player on the Exit — a mob wandering into the door won't finish the level (CharacterBody2D).
  • When the array runs out, the win screen loads — that's the one real change_scene_to_file left in the flow.
💡Testing a specific level

Change load_level(0) in _ready() to load_level(2) to jump straight to level 3 while testing. Just change it back before the showcase.

#Go to a game-over screen

func game_over():
	get_tree().change_scene_to_file("res://GameOver.tscn")

#Quit (optional)

func _on_quit_pressed():
	get_tree().quit()
💡Minimum for "looks finished"

A title screen with your game's name + team names, and a way to restart. That's the Day 5 polish bar (Day 5 - Polish and Showcase). You don't need a separate game-over scene — reusing the title screen is fine.

⚠️Carrying the score between scenes

When you change_scene_to_file, the old scene (and its variables) is destroyed, so the score resets. To show the final score on a game-over screen, store it in an autoload/global script — that's Autoload and Global. Only attempt it if your team has time.
