"Juice" = small effects that make the game feel alive — screen shake, pops, flashes, particles. None of it changes the rules; all of it changes how the game feels to play.

⚠️Juice comes last

Only add juice once your game runs without crashing and the full start → play → lose → restart loop works. Juice added in a hurry is the #1 way to break a working game right before a showcase.

Each effect below is self-contained: it plugs into a script you already have (your hit/game-over function, your pickup script, etc.). Node names are examples — swap in your project's actual names.

#Camera shake when the player is hit

Where it goes: the script on whatever node owns your camera — usually the Player.

  1. Select your Player in the Scene dock → Ctrl+A → add Camera2D (if you don't already have one). In the Inspector, make sure Enabled is checked.
  2. Add this function to that node's script:
func screen_shake():
	var tween = create_tween()
	for i in 6:
		var offset = Vector2(randf_range(-8, 8), randf_range(-8, 8))
		tween.tween_property($Camera2D, "offset", offset, 0.03)
	tween.tween_property($Camera2D, "offset", Vector2.ZERO, 0.03)
  1. Call screen_shake() from wherever the hit happens — e.g. inside your _on_body_entered or game_over() function.
  2. Press F5 and get hit — the screen should jitter for a fraction of a second, then settle.
  • create_tween() — animates a property over time from code, no animation editor needed.
  • The last line resets the camera to center so the game doesn't stay crooked.

#A quick scale pop when a pickup is collected

Where it goes: your pickup's script (the Area2D from Area2D).

Replace the instant queue_free() with a short grow-then-shrink tween first:

func _on_body_entered(_body):
	collected.emit()
	var tween = create_tween()
	tween.tween_property($Sprite2D, "scale", Vector2(1.4, 1.4), 0.1)
	tween.tween_property($Sprite2D, "scale", Vector2(1.0, 1.0), 0.1)
	await tween.finished
	queue_free()
  • await tween.finished — waits for the pop to finish before deleting the node, so the player actually sees it.
  • If your pickup uses AnimatedSprite2D instead of Sprite2D, change the node path to match.

#A flashing player when in danger

Where it goes: your Player's script.

  1. Select Player → Ctrl+A → add Timer → rename DangerTimer → set Wait Time to 0.1 in the Inspector.
  2. Select DangerTimer → Signals tab → double-click timeout → Connect to the Player's script.
  3. In the connected function, toggle visibility; start/stop the timer whenever "danger" begins and ends in your game:
func _on_danger_timer_timeout():
	$AnimatedSprite2D.visible = not $AnimatedSprite2D.visible

func start_danger():
	$DangerTimer.start()

func end_danger():
	$DangerTimer.stop()
	$AnimatedSprite2D.visible = true
  • The end_danger() reset matters — without it the player can end up invisible forever.

#A particle burst on death

Full node reference: Particles.

Where it goes: your Main scene (not the Player — the burst has to survive even when the player is hidden).

  1. Select Main → Ctrl+A → add GPUParticles2D → rename DeathParticles.
  2. In the Inspector: uncheck Emitting, check One Shot, set Amount to 16, Lifetime to 0.6.
  3. Under Process Material, click [empty] → New ParticleProcessMaterial → expand it → set Spread to 180 and Initial Velocity Min/Max to about 100/200 for an even outward burst.
  4. Trigger it in main.gd, wherever your game-over logic runs:
func game_over():
	$DeathParticles.global_position = $Player.global_position
	$DeathParticles.restart()
	$DeathParticles.emitting = true
	# ...then whatever else your game_over already does
  1. Press F5 and die on purpose — you should see a burst of particles right where the player was.
