An enemy that chases you. The Day 1 tutorial mobs are RigidBody2Ds that get a velocity once and drift in a straight line forever. A homing mob steers toward the player every frame instead. Builds on Spawning and Timers; the predictable cousin that walks a fixed route is Patrol Enemies, and Enemy States combines the two.

#Step 1: put the player in a group

The mob needs a way to find the player. Groups are the easiest way:

  1. Select your Player node.
  2. In the Node panel (right side, next to the Inspector) → Groups tab.
  3. Type player → Add.

Now any script in the game can ask for it by name. Do this before anything else — it's the step everyone forgets.

#Step 2: the homing script

Attach this to the mob's RigidBody2D root (or duplicate mob.tscn first and attach it to the copy):

extends RigidBody2D

@export var speed = 180.0
@export var turn_rate = 0.04  # lower = wider, lazier turns
var player: Node2D

func _ready():
	player = get_tree().get_first_node_in_group("player")

func _physics_process(delta):
	if player and player.visible:
		var target_dir = (player.global_position - global_position).normalized()
		linear_velocity = linear_velocity.lerp(target_dir * speed, turn_rate)
		rotation = linear_velocity.angle()

Line by line:

  • get_first_node_in_group("player") — grabs the player without hardcoding a path like $"../../Player", which breaks the moment a mob is spawned into a different parent.
  • .normalized() — turns "the player is 300 pixels that way" into a pure direction of length 1, so speed is the only thing controlling how fast the mob moves.
  • .lerp(..., turn_rate) — this is the line that makes it feel good. Snapping linear_velocity straight to the target direction gives you an unavoidable heat-seeker. Lerping gives the mob turning momentum, so a quick sidestep can make it overshoot and swing around. Tune turn_rate between about 0.02 and 0.1 to taste.
  • player.visible — stops mobs from swarming your corpse after a hit, since the tutorial hides the player on death.
  • rotation = linear_velocity.angle() — points the sprite where it's heading. Delete this line if your art shouldn't rotate.

#Mixing chasers and drifters

You don't need two separate mob scenes. Add an exported flag to your existing mob and only run the steering when it's on:

@export var is_homing = false

Then in your spawn code (Spawning and Timers), flip a coin so some creeps drift and some chase:

mob.is_homing = randf() < 0.3   # about 1 in 3 hunts you

A field of drifters with the occasional hunter reads as much more dangerous than a field of pure hunters — the player can't tell which is which until it turns.

⚠️Homing mobs get stuck on walls

If your mobs' collision mask includes the obstacles layer (Obstacles), homing mobs will grind against walls forever — RigidBodies don't path around things. Either let mobs ignore obstacles (mask excludes the obstacles layer, so they pass through) or accept that walls double as mob shields, which honestly can be a fun mechanic. Decide on purpose. See CharacterBody2D.
