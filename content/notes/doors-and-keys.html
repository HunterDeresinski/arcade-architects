🏠 Curriculum Map · 🧩 Mechanics Index · Used on Day 3 - Design Day, Day 4 - Production Day

A door that won't open until you find the key. This is the smallest possible progression mechanic — and progression is what turns a room full of stuff into a level. Builds on Collectables and Area2D.

#Why this mechanic matters

Coins give the player something to do. A locked door gives them a reason to explore. The instant you add one, your level has structure: this part first, then that part. Teams that add a key and a door on Day 4 almost always end up with a better-feeling game than teams that add more enemies.

#The key

A collectable that sets a flag instead of adding score.

Key             (Area2D)   Layer: pickups, Mask: player
├── Sprite       (Sprite2D)
└── Shape        (CollisionShape2D)
extends Area2D

@export var key_color = "gold"

func _on_body_entered(body):
	if body.is_in_group("player"):
		body.add_key(key_color)
		$PickupSound.play()
		queue_free()

@export var key_color means one key scene handles gold, blue, and red keys — set it per instance in the Inspector.

#The player holds the keys

In the player script:

var keys = {}

func add_key(color):
	keys[color] = keys.get(color, 0) + 1
	keys_changed.emit(keys)

func use_key(color) -> bool:
	if keys.get(color, 0) > 0:
		keys[color] -= 1
		keys_changed.emit(keys)
		return true
	return false

A Dictionary ({}) maps color → how many you're carrying. keys.get(color, 0) reads a count and returns 0 if you've never picked that color up, instead of erroring.

use_key() returns true/false, so the door can ask "may I open?" and get an answer in one line. Declare signal keys_changed(keys) at the top to drive a UI display (Label and CanvasLayer).

💡Simplest possible version

If dictionaries feel like too much for your team, use var has_key = false on the player and be done. You lose multiple key colors and gain ten minutes. That's often the right trade on Day 4.

#The door

A door needs to do two things: block the player, and notice them. That's two nodes (Area2D can't block, StaticBody2D can't detect):

Door              (StaticBody2D)  Layer: obstacles, Mask: none
├── Sprite         (Sprite2D)
├── Shape          (CollisionShape2D)
└── Interact       (Area2D)  Layer: none, Mask: player
    └── Shape      (CollisionShape2D)   ← a bit bigger than the door
extends StaticBody2D

@export var key_color = "gold"
@export var auto_open = true      # false = press a key to open

var player_nearby: Node = null
var is_open = false

func _on_interact_body_entered(body):
	if not body.is_in_group("player"):
		return
	player_nearby = body
	if auto_open:
		try_open(body)

func _on_interact_body_exited(body):
	if body == player_nearby:
		player_nearby = null

func _unhandled_input(event):
	if not auto_open and player_nearby and event.is_action_pressed("interact"):
		try_open(player_nearby)

func try_open(body):
	if is_open:
		return
	if body.use_key(key_color):
		open()
	else:
		$LockedSound.play()
		bump()

func open():
	is_open = true
	$OpenSound.play()
	$Sprite.play("open")
	$Shape.set_deferred("disabled", true)   # stop blocking
	create_tween().tween_property($Sprite, "modulate:a", 0.0, 0.3)

func bump():
	var t = create_tween()
	t.tween_property($Sprite, "position:x", 4, 0.05).as_relative()
	t.tween_property($Sprite, "position:x", -8, 0.05).as_relative()
	t.tween_property($Sprite, "position:x", 4, 0.05).as_relative()

The three things that make this feel good:

  • set_deferred on the shape — disabling a CollisionShape2D during a collision callback errors without it.
  • bump() — the door shakes when it's locked. Without feedback, players think the game is broken. Three lines, huge difference.
  • The locked sound. A locked door that's silent reads as a bug.

Add interact to Project Settings → Input Map (E is the convention) if you use manual opening.

#Showing what you're carrying

func _on_keys_changed(keys):
	$UI/GoldKeyIcon.visible = keys.get("gold", 0) > 0
	$UI/KeyCount.text = "Keys: %d" % keys.get("gold", 0)

If the player can't see they have the key, they won't think to go back to the door.

#Variations worth stealing

A door to the next level — no key, just an exit (Scene Switching):

func _on_body_entered(body):
	if body.is_in_group("player"):
		get_tree().change_scene_to_file("res://level_2.tscn")

Collect-them-all gate — the exit opens once every coin is gone. Pairs with the counting code in Collectables:

func _process(_delta):
	if not is_open and get_tree().get_nodes_in_group("coins").is_empty():
		open()

A pressure plate — an Area2D that opens a door while something stands on it:

extends Area2D

@export var door_path: NodePath

func _on_body_entered(_b): get_node(door_path).open()
func _on_body_exited(_b):
	if get_overlapping_bodies().is_empty():
		get_node(door_path).close()

@export var door_path: NodePath gives you a drag-and-drop slot in the Inspector — point the plate at its door by dragging, no code. This is the single most useful export type for level design.

A lever or switch — same as a plate, but toggles instead of holding.

A boss key — the door only opens when the boss is dead. if get_tree().get_nodes_in_group("bosses").is_empty(): open().

A one-way door — opens, then disables its own Interact area behind you.
