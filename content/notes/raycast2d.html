An invisible laser pointer that reports the first thing it hits. Used for ground checks, ledge detection, line of sight, vision cones, and hitscan weapons.

#Setup

Add a RayCast2D child. Two properties matter:

  • Target Position — where the ray points, relative to the node. (0, 40) points 40px down. You can see the line in the editor.
  • Enabled — must be checked, or it does nothing.

Set its collision mask to what it should notice (Collision Layers and Masks).

#Reading it

if $RayCast2D.is_colliding():
	var what  = $RayCast2D.get_collider()          # the node it hit
	var where = $RayCast2D.get_collision_point()   # global position of the hit
	var norm  = $RayCast2D.get_collision_normal()  # surface direction
⚠️Rays update once per physics frame

If you move or rotate a ray and check it in the same frame, you get the old answer. Call $RayCast2D.force_raycast_update() first.

#What people actually use it for

Ledge detection — an enemy that doesn't walk off cliffs. The single most useful raycast in a platformer. Point a ray down, just in front of the enemy's feet:

func do_patrol(_delta):
	velocity.x = direction * speed
	if is_on_wall() or not $LedgeCheck.is_colliding():
		direction *= -1
		$LedgeCheck.position.x = 12 * direction    # move the ray to the new front

Upgrade this straight into Patrol Enemies — it's the difference between a Goomba and a Goomba that keeps falling in the pit.

Line of sight — an enemy that can't see through walls. Fixes the main weakness of Enemy States:

func can_see_player():
	if player == null:
		return false
	$SightRay.target_position = to_local(player.global_position)
	$SightRay.force_raycast_update()
	if not $SightRay.is_colliding():
		return true
	return $SightRay.get_collider() == player      # hit the player first = clear view

Set the ray's mask to obstacles and player, so whichever comes first tells you the truth.

A vision cone (stealth games). Three or five rays fanned out, plus an angle check:

func player_in_cone():
	var to_player = player.global_position - global_position
	var facing = Vector2.RIGHT.rotated(rotation)
	if to_player.length() > view_distance:
		return false
	if facing.angle_to(to_player) > deg_to_rad(35):    # 70-degree cone
		return false
	return can_see_player()                            # and nothing blocking

A hitscan weapon — a laser that hits instantly, no bullet to travel:

func fire_laser():
	$Ray.target_position = Vector2(1200, 0)
	$Ray.force_raycast_update()
	var end = $Ray.get_collision_point() if $Ray.is_colliding() else $Ray.to_global(Vector2(1200,0))
	$Line2D.points = [Vector2.ZERO, $Line2D.to_local(end)]
	if $Ray.is_colliding() and $Ray.get_collider().has_method("take_damage"):
		$Ray.get_collider().take_damage(1)

Pairs with Line2D for the visible beam.

Wall-jump detection — a ray each side; if it's colliding and you're not on the floor, you can wall-jump (Dash and Double Jump).

"Press E to open" — a short forward ray finds the nearest interactable, better than an Area2D when you want the one you're facing (Doors and Keys).

#ShapeCast2D

A ShapeCast2D is the same idea with a whole shape instead of a line, and it can report several hits. Use it when a thin ray keeps slipping past small objects.
