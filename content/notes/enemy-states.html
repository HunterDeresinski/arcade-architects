Difficulty: ⭐⭐ moderate · Payoff: ⭐⭐⭐ high · Time: 30 minutes

An enemy that patrols until it notices you, chases you, attacks when close, then gives up and goes home. Patrol Enemies and Homing Enemies are the two halves; this is the note that joins them into something that feels alive.

#The idea

An enemy is in exactly one state at a time, and each state has its own behaviour and its own rules for switching. That's it — no framework required, just an enum and a match.

IDLE ──sees you──> CHASE ──close enough──> ATTACK
  ↑                  │                        │
  └──lost you────────┘<───────────────────────┘

#The whole thing

extends CharacterBody2D

enum State { IDLE, PATROL, CHASE, ATTACK, HURT }

@export var patrol_speed = 60.0
@export var chase_speed = 140.0
@export var attack_range = 40.0
@export var give_up_distance = 400.0

var state = State.PATROL
var player: Node2D = null
var patrol_direction = 1

func _physics_process(delta):
	match state:
		State.IDLE:    do_idle(delta)
		State.PATROL:  do_patrol(delta)
		State.CHASE:   do_chase(delta)
		State.ATTACK:  do_attack(delta)
		State.HURT:    do_hurt(delta)
	move_and_slide()

func change_state(new_state):
	if state == new_state:
		return
	state = new_state
	match state:                        # things that happen ONCE on entering
		State.PATROL: $Sprite.play("walk")
		State.CHASE:  $Sprite.play("run");    $AlertSound.play()
		State.ATTACK: $Sprite.play("attack"); velocity = Vector2.ZERO
		State.IDLE:   $Sprite.play("idle");   velocity = Vector2.ZERO
		State.HURT:   $Sprite.play("hurt")

enum creates named numbers — State.CHASE instead of 2. match is GDScript's switch: it runs only the branch that matches.

change_state() is where "entry actions" go — the alert sound plays once when the chase begins, not sixty times a second. That separation is the whole reason to write it as a function.

#The states

func do_patrol(_delta):
	velocity.x = patrol_direction * patrol_speed
	if is_on_wall():
		patrol_direction *= -1              # same as Patrol Enemies
		$Sprite.flip_h = patrol_direction < 0
	if can_see_player():
		change_state(State.CHASE)

func do_chase(_delta):
	if player == null:
		change_state(State.PATROL)
		return
	var to_player = player.global_position - global_position
	velocity = to_player.normalized() * chase_speed
	$Sprite.flip_h = to_player.x < 0

	if to_player.length() < attack_range:
		change_state(State.ATTACK)
	elif to_player.length() > give_up_distance:
		player = null
		change_state(State.PATROL)

func do_attack(_delta):
	velocity = Vector2.ZERO             # committed -- can't move while swinging

func do_idle(_delta):
	velocity = Vector2.ZERO
	if can_see_player():
		change_state(State.CHASE)

func do_hurt(_delta):
	pass                                 # knockback code moves us; just wait

#Seeing the player

The simplest version — an Area2D "aggro zone" child:

func _on_aggro_body_entered(body):
	if body.is_in_group("player"):
		player = body

func _on_aggro_body_exited(body):
	if body == player:
		pass          # don't clear immediately -- give_up_distance handles it

func can_see_player():
	return player != null

A better version that can't see through walls uses a RayCast2D — that note covers vision cones and line-of-sight properly.

#Making states end

ATTACK and HURT need to finish and hand control back:

func attack_finished():                    # called by the animation, or a Timer
	change_state(State.CHASE)

func take_damage(amount):
	health -= amount
	change_state(State.HURT)
	await get_tree().create_timer(0.3).timeout
	if health <= 0:
		die()
	else:
		change_state(State.CHASE)

Connect AnimationPlayer's animation_finished signal, or use a Timer — either works.

#Why this is worth the extra code

Compare a plain chaser to this:

Plain chaserState-based enemy
Beelines at you from across the levelPatrols its own area until it notices you
Attacks constantly while touchingWinds up, strikes, recovers — you can dodge it
Follows foreverLoses interest and goes home
Same behaviour alwaysReacts to being hit

The second one reads as a creature with intentions. Players describe it as "smart" even though it's about forty lines.

#Variations

Add a SEARCH state — walk to where it last saw you, look around for two seconds, then give up. Enormous perceived-intelligence gain for one extra state.

Add a FLEE state — run away below 25% health. Instantly memorable.

A boss with phases — PHASE_1, PHASE_2, ENRAGED, switching on health thresholds. Same pattern, bigger enemy:

func take_damage(amount):
	health -= amount
	if health < max_health * 0.5 and state != State.PHASE_2:
		change_state(State.PHASE_2)

A guard on a timer — IDLE for 3 seconds, PATROL for 5, repeat. Feels far more natural than constant motion.

A sleeping enemy — starts IDLE, wakes on noise or proximity. Great with a stealth RayCast2D vision cone.

#Debugging states

Put the state on screen while you build it:

func _process(_delta):
	$StateLabel.text = State.keys()[state]

State.keys() gives the names as text. This turns "why is it doing that?" into something you can just look at, and it's the fastest debugging trick in this note.

#Common problems

ProblemFix
Sound plays every frameEntry actions are in _physics_process instead of change_state()
Enemy freezes foreverA state with no exit — ATTACK and HURT must lead somewhere
Flickers between two statesChase and give-up thresholds are the same number. Make give-up distance clearly larger
Never notices the playerAggro Area2D missing a shape, or wrong mask
Ignores damagetake_damage doesn't call change_state(State.HURT)
Chases through wallsAdd a RayCast2D line-of-sight check
💡Hysteresis, in one sentence

Make the distance to stop chasing bigger than the distance to start. Equal thresholds cause an enemy that rapidly flickers between states at the boundary. This applies to almost every threshold in game AI.
