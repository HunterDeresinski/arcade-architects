Hearts, HP, getting hurt, invincibility frames, dying, and respawning. This is the note every damage-dealing thing points at — Hazards, Patrol Enemies, and Making Bullets all end in "call take_damage()", and this is where that function lives.

#Where health should live

Put it on the player, in the player's own script. Not in a global, not in Main. Everything that hurts the player then calls one function, and there's only one place to debug.

Player               (CharacterBody2D)  Layer: player, Mask: obstacles
├── Sprite            (AnimatedSprite2D)
├── Shape             (CollisionShape2D)
├── Hurtbox           (Area2D)  Layer: none, Mask: mobs, hazards, bullets
│   └── HurtShape     (CollisionShape2D)
└── InvincibleTimer   (Timer)   One Shot ON, Autostart OFF, Wait Time 1.0

Layers come from Collision Layers and Masks. The Hurtbox is a separate Area2D so that moving and getting hit stay separate jobs.

#The player health script

Add this to your existing player script — it sits alongside your movement code, it doesn't replace it.

extends CharacterBody2D

signal health_changed(current, maximum)
signal died

@export var max_health = 3
var health: int
var invincible = false

func _ready():
	add_to_group("player")
	health = max_health
	health_changed.emit(health, max_health)

func take_damage(amount = 1):
	if invincible or health <= 0:
		return                      # already hurt, or already dead
	health -= amount
	health_changed.emit(health, max_health)

	if health <= 0:
		die()
	else:
		start_invincibility()
		$HurtSound.play()

func heal(amount = 1):
	health = min(health + amount, max_health)
	health_changed.emit(health, max_health)

func start_invincibility():
	invincible = true
	$InvincibleTimer.start()
	flash()

func _on_invincible_timer_timeout():
	invincible = false
	modulate.a = 1.0

func die():
	died.emit()
	set_physics_process(false)
	$Sprite.play("death")
	await get_tree().create_timer(1.0).timeout
	respawn()

Connect InvincibleTimer's timeout signal to _on_invincible_timer_timeout (Signals).

Why the invincible guard is the first line: without it, standing in lava calls take_damage() sixty times a second and you lose three hearts instantly. The guard is what makes damage feel fair.

#The hurtbox connection

Connect the Hurtbox's area_entered signal:

func _on_hurtbox_area_entered(area):
	var amount = area.damage if "damage" in area else 1
	take_damage(amount)

"damage" in area checks whether that node has a damage property. So a spike can @export var damage = 1 and a boss laser can set 3, and the player handles both without knowing what hit it.

For enemies that are bodies rather than areas, connect body_entered the same way.

#The invincibility flash

I-frames the player can't see feel like a bug. Blink during them:

func flash():
	var t = create_tween().set_loops(6)
	t.tween_property(self, "modulate:a", 0.2, 0.08)
	t.tween_property(self, "modulate:a", 1.0, 0.08)

Six blinks at 0.16s each ≈ 1 second, matching the Timer. More options in Juice and Game Feel; the tween syntax itself is explained in Tweens.

#Showing hearts

Under a CanvasLayer, an HBoxContainer with one TextureRect per heart (Label and CanvasLayer):

UI            (CanvasLayer)
└── Hearts     (HBoxContainer)
    ├── Heart1  (TextureRect)
    ├── Heart2  (TextureRect)
    └── Heart3  (TextureRect)

In your Main script, listen for the signal instead of checking every frame:

func _ready():
	$Player.health_changed.connect(_on_health_changed)
	$Player.died.connect(_on_player_died)

func _on_health_changed(current, _maximum):
	for i in $UI/Hearts.get_child_count():
		$UI/Hearts.get_child(i).visible = i < current

Signals, not polling. The UI updates exactly when health changes, and the player script never needs to know the UI exists. That separation is worth pointing out — it's why the same player scene drops into any level.

#Or a health bar

Add a ProgressBar instead:

func _on_health_changed(current, maximum):
	$UI/HealthBar.max_value = maximum
	$UI/HealthBar.value = current

Nicer, animated:

create_tween().tween_property($UI/HealthBar, "value", current, 0.3)

#Respawning

Drop a SpawnPoint Marker2D in the level and drag it where the player should appear.

func respawn():
	health = max_health
	health_changed.emit(health, max_health)
	velocity = Vector2.ZERO
	global_position = get_tree().current_scene.get_node("SpawnPoint").global_position
	$Sprite.play("idle")
	set_physics_process(true)
	start_invincibility()      # don't respawn into the thing that killed you

That last line matters more than it looks. Respawning without i-frames into a room full of enemies is an instant death loop.

#Checkpoints

An Area2D the player walks through that moves the spawn point:

extends Area2D

func _on_body_entered(body):
	if body.is_in_group("player"):
		get_tree().current_scene.get_node("SpawnPoint").global_position = global_position
		$Sprite.play("activated")
		set_deferred("monitoring", false)

#Lives on top of health

Health is per-attempt; lives are how many attempts you get. Keep them in Main, not the player:

var lives = 3

func _on_player_died():
	lives -= 1
	$UI/LivesLabel.text = "Lives: %d" % lives
	if lives <= 0:
		get_tree().change_scene_to_file("res://game_over.tscn")   # see Scene Switching

Since the player already respawns itself, Main only decides whether that's allowed to happen again.

#Enemies with health too

Same idea, smaller:

extends CharacterBody2D

@export var health = 3

func take_damage(amount = 1):
	health -= amount
	modulate = Color.RED
	await get_tree().create_timer(0.1).timeout
	modulate = Color.WHITE
	if health <= 0:
		queue_free()

A bullet then works on anything: if body.has_method("take_damage"): body.take_damage(damage). Player, enemy, breakable crate — all the same call (Making Bullets).

#Falling out of the world

A wide, thin Area2D under the whole level:

func _on_death_zone_body_entered(body):
	if body.is_in_group("player"):
		body.take_damage(99)
