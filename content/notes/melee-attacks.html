A sword swing, a punch, a spear jab. Making Bullets covers shooting; this covers hitting things that are right in front of you — which is what roughly half of teams actually want.

#The idea: a hitbox that turns on briefly

A melee attack is an Area2D that is off most of the time and on for a fraction of a second. Everything else is timing and feel.

Hitbox = deals damage. Hurtbox = receives it. Keep the words straight and the rest follows (Collision Layers and Masks).

Player                 (CharacterBody2D)  Layer: player, Mask: obstacles
├── Sprite              (AnimatedSprite2D)
├── Shape               (CollisionShape2D)
├── Hurtbox             (Area2D)  Mask: mobs, hazards       ← takes damage
│   └── HurtShape
└── SwordPivot          (Node2D)                            ← rotate this to aim
    └── Hitbox          (Area2D)  Layer: none, Mask: mobs   ← deals damage
        └── HitShape    (CollisionShape2D)  disabled by default

The SwordPivot is a plain Node2D with the Hitbox offset to the right of it. Rotate the pivot and the whole swing arc rotates with it — the same trick as the orbiting spike ball.

#The attack script

extends CharacterBody2D

@export var damage = 1
@export var attack_duration = 0.15

var is_attacking = false

func _ready():
	$SwordPivot/Hitbox.monitoring = false
	$SwordPivot.hide()

func _physics_process(_delta):
	# ...your normal movement...
	face_attack_direction()

	if Input.is_action_just_pressed("attack") and not is_attacking and $AttackCooldown.is_stopped():
		attack()

func face_attack_direction():
	if is_attacking:
		return                                   # don't re-aim mid-swing
	var aim = Input.get_vector("move_left", "move_right", "move_up", "move_down")
	if aim != Vector2.ZERO:
		$SwordPivot.rotation = aim.angle()

func attack():
	is_attacking = true
	$AttackCooldown.start()
	$SwingSound.play()
	$Sprite.play("attack")

	$SwordPivot.show()
	$SwordPivot/Hitbox.monitoring = true
	swing_animation()

	await get_tree().create_timer(attack_duration).timeout

	$SwordPivot/Hitbox.monitoring = false
	$SwordPivot.hide()
	is_attacking = false

func swing_animation():
	var start = $SwordPivot.rotation - 0.7
	var end   = $SwordPivot.rotation + 0.7
	$SwordPivot.rotation = start
	create_tween().tween_property($SwordPivot, "rotation", end, attack_duration)

Add attack to Project Settings → Input Map (J, Z, or left mouse are all fine), and an AttackCooldown Timer (One Shot ✅, Wait Time ~`0.35`).

monitoring = false is cleaner than disabling the shape — no set_deferred needed (Area2D).

#Dealing the damage

Connect the Hitbox's body_entered (or area_entered if your enemies use hurtboxes):

func _on_hitbox_body_entered(body):
	if body.has_method("take_damage"):
		body.take_damage(damage)
		knockback(body)
		hit_stop()

has_method("take_damage") means the same sword hurts enemies, breakable crates, and boss weak points without any special cases (Health and Lives).

#The three things that make melee feel good

Melee lives or dies on feedback. A sword that silently deletes an enemy feels like nothing. These three take about ten minutes total and they're the whole difference.

1. Knockback — shove the target away:

func knockback(target):
	if not "knockback_velocity" in target:
		return
	var dir = (target.global_position - global_position).normalized()
	target.knockback_velocity = dir * 350.0

On the enemy:

var knockback_velocity = Vector2.ZERO

func _physics_process(delta):
	if knockback_velocity.length() > 5:
		velocity = knockback_velocity
		knockback_velocity = knockback_velocity.move_toward(Vector2.ZERO, 900 * delta)
	else:
		# ...normal AI movement...
		pass
	move_and_slide()

2. Hit-stop — freeze the whole game for a few frames on impact. This is the secret ingredient in every game that feels good to hit things in:

func hit_stop(duration = 0.06):
	Engine.time_scale = 0.05
	await get_tree().create_timer(duration * 0.05, true, false, true).timeout
	Engine.time_scale = 1.0

The true flags make the timer ignore time_scale, so it isn't slowed by the very slowdown it's timing. Sixty milliseconds is invisible as a pause and enormous as a feeling.

3. A flash and a sound. The enemy flashes white, a sound plays. Both are in Juice and Game Feel. Add a little Camera2D shake on a heavy hit.

#Better timing with AnimationPlayer

The version above uses a fixed attack_duration. Better: let the animation decide exactly when the blade is dangerous, using Call Method tracks (AnimationPlayer):

# these get called by keyframes on the attack animation's timeline
func enable_hitbox():  $SwordPivot/Hitbox.monitoring = true
func disable_hitbox(): $SwordPivot/Hitbox.monitoring = false

Now the designer tunes the attack by dragging keyframes — wind-up, active frames, recovery — instead of guessing at numbers. This is how fighting games are built.

#Variations

Charge attack — hold to charge, release for more damage:

if Input.is_action_pressed("attack"):
	charge = min(charge + delta, 1.5)
	$ChargeBar.value = charge / 1.5
elif Input.is_action_just_released("attack") and charge > 0:
	damage = 1 + int(charge * 2)
	attack()
	charge = 0.0

Combo — chain up to three swings if you press again during the recovery window. Track combo_index, reset it with a Timer.

Spin attack — rotate the pivot a full TAU and leave the hitbox on for the whole rotation.

Stomp (jump on their head) — no hitbox needed; already covered in Patrol Enemies.

Enemy melee — the mirror image: an enemy hitbox masking player, telegraphed by a wind-up animation. Always telegraph. An enemy that attacks instantly is unfair; one that raises its arm for 0.4 seconds first is a fight.

ProblemFix
Sword hits nothingHitbox monitoring never turned on, missing CollisionShape2D, or mask doesn't include mobs
One swing kills everything on screenHitbox is enormous, or it never turns off
Enemy takes damage many times per swingAdd an already_hit array cleared at the start of each attack
Sword hurts the playerHitbox layer is mobs, or the player's Hurtbox masks its own hitbox
Attack feels floatyYou're missing knockback and hit-stop, not damage numbers
Can attack infinitely fastAttackCooldown not started, or One Shot is off

The multi-hit fix:

var already_hit = []

func attack():
	already_hit.clear()
	# ...rest of attack...

func _on_hitbox_body_entered(body):
	if body in already_hit:
		return
	already_hit.append(body)
	# ...deal damage...
