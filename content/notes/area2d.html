The detector. An Area2D notices when something overlaps it and fires a signal — but it never blocks anything. Getting hit, collecting a coin, walking into lava, reaching the goal: all Area2D.

#Area2D is not a body

This is the thing to understand first. Godot's physics bodies (CharacterBody2D, StaticBody2D and RigidBody2D) have physical presence — they stop things. An Area2D has awareness — it notices things and does nothing about it.

Blocks movementDetects overlaps
Area2D❌✅
StaticBody2D✅❌
CharacterBody2D✅❌ (by itself)

That's why the Day 1 Area2D player walks straight through walls (Obstacles fixes this), and why a CharacterBody2D player needs a child Area2D to notice it got hit.

#The setup

An Area2D needs a CollisionShape2D child. Without one it detects nothing — this is the #1 mistake in the camp.

Coin            (Area2D)
├── Sprite       (Sprite2D)
└── Shape        (CollisionShape2D)  ← assign a CircleShape2D in the Inspector

#The four signals

Connect these in the Node dock (Signals → Connecting a signal in the editor the easy way):

SignalFires when
body_entered(body)a PhysicsBody enters — the CharacterBody2D player, a RigidBody2D mob
body_exited(body)that body leaves
area_entered(area)another Area2D enters — a bullet, another hurtbox
area_exited(area)that area leaves

Body or area? Look at what's coming in. A CharacterBody2D player → body_entered. A bullet that's an Area2D → area_entered. If your signal never fires, this is the second thing to check (after the missing shape).

extends Area2D

func _on_body_entered(body):
	print("Something touched me: ", body.name)

#Making sure it's the player

Three ways, worst to best:

if body.name == "Player":          # breaks the moment someone renames the node
if body is CharacterBody2D:        # true of enemies too
if body.is_in_group("player"):     # ✅ use this one

Put the player in a group: select the Player node → Node dock → Groups tab → type player → Add. Now every pickup, hazard, and trigger in the game can ask the same question, and it keeps working when someone renames things on Day 4.

Better still, skip the check entirely by setting up Collision Layers and Masks so only the player can ever trigger it. Then the signal firing is the answer.

#What people actually do with an Area2D

Pickups — coin, heart, key. Add points, then delete itself. Full build in Collectables:

extends Area2D
signal collected

func _on_body_entered(body):
	if body.is_in_group("player"):
		collected.emit()
		queue_free()

queue_free() removes the node from the game. It's what makes a coin actually disappear.

A hurtbox — a child Area2D whose only job is noticing damage, so the parent body can focus on moving. The core pattern of Collision Layers and Masks and Health and Lives:

func _on_hurtbox_area_entered(area):
	take_damage(1)

A hazard — lava, spikes, a bottomless pit. Doesn't block, just hurts (Hazards).

A trigger zone — an invisible Area2D with no sprite. Walk in, and something happens: a door opens, a boss wakes up, a checkpoint saves, the level ends.

func _on_body_entered(body):
	if body.is_in_group("player"):
		get_tree().change_scene_to_file("res://level_2.tscn")

A bullet — bullets are almost always Area2Ds. You want them to notice a hit, not physically shove the enemy across the room (Making Bullets).

A screen-exit cleanup zone — or use VisibleOnScreenNotifier2D, which does the same job with less setup.

An enemy's aggro range — a big circle around the enemy. Player enters, the enemy starts chasing (Homing Enemies):

func _on_aggro_body_entered(body):
	if body.is_in_group("player"):
		chasing = true

func _on_aggro_body_exited(body):
	if body.is_in_group("player"):
		chasing = false

#Asking "who's in here right now?"

Signals tell you the moment something enters. Sometimes you want to know the current state instead:

var bodies = $Hurtbox.get_overlapping_bodies()
var areas  = $Hurtbox.get_overlapping_areas()
if bodies.size() > 0:
	take_damage(1)   # continuous damage while standing in lava

This is how you make lava hurt every frame instead of only on the first touch.

#Turning one off

$Hurtbox.monitoring = false   # stop detecting (i-frames, dash-through-enemies)
$Hurtbox.monitoring = true    # back on

Cleaner than disabling the CollisionShape2D and doesn't need set_deferred.

#Other Area2D properties

  • Priority — which area wins when several overlap.
  • Gravity / Gravity Point — an Area2D can override gravity inside it. A gravity point makes a little planet that pulls RigidBody2Ds toward its center. Rarely needed, always a hit.
  • Audio Bus Override — reverb inside a cave. Pure polish (AudioStreamPlayer).
⚠️If nothing happens when things overlap

Check in this order: (1) Is there a CollisionShape2D with an actual Shape assigned? (2) Did you connect the signal, and is it the right one (body_ vs area_)? (3) Do the layers and masks let them see each other? (4) Turn on Debug → Visible Collision Shapes and look.
