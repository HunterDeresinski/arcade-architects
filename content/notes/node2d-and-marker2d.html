The two most boring nodes in Godot, and two of the most useful. Node2D is an empty thing with a position — every other 2D node is built on it. Marker2D is a Node2D you can actually see in the editor, used to mark a spot.

#Node2D: what every 2D node inherits

Every property below works on CharacterBody2D, Area2D, Sprite2D, all of them — because they're all Node2Ds underneath.

position          # Vector2, relative to the parent
global_position   # Vector2, relative to the world
rotation          # radians. rotation_degrees if you prefer degrees
scale             # Vector2(1, 1) is normal size
visible           # true/false -- or use show() / hide()
modulate          # Color tint. Color.RED to flash, Color(1,1,1,0.5) for half-transparent
z_index           # draw order. Higher draws on top
❗position vs global_position

position is measured from the parent. If your Bullet is a child of the Gun, setting position = Vector2.ZERO puts it on the gun, not at the world origin. When something looks like it teleported to the top-left corner, this is almost always why. Use global_position when you mean "this exact spot in the world."

#What people actually do with a plain Node2D

1. As a container to organize the scene tree. Free, costs nothing, makes a messy scene readable:

Main
├── World         (Node2D)
│   ├── TileMapLayer
│   └── Obstacles
├── Enemies       (Node2D)   ← spawn every enemy in here
├── Bullets       (Node2D)   ← and every bullet in here
└── UI            (CanvasLayer)
$Enemies.add_child(new_enemy)   # tidy tree instead of 200 loose nodes

2. As a group handle — move the parent, move everything. This is the trick behind Enemy Formations: put fifty aliens under one Node2D, move the Node2D, and all fifty march in perfect formation with one script instead of fifty.

3. To clear a whole category at once:

for bullet in $Bullets.get_children():
	bullet.queue_free()

4. As a pivot to rotate around. Rotating a child rotates it in place; rotating its parent swings the child around the parent. That's how you make an orbiting shield or a swinging spike ball:

# script on the pivot Node2D, spike is a child offset 80px to the right
func _process(delta):
	rotation += 2.0 * delta

#Marker2D: an X on the map

A Node2D that draws a little cross in the editor so you can see and drag it. It has no effect on the running game — it's purely a named position.

#What people actually do with a Marker2D

Spawn points. Add Muzzle as a child of the gun, drag it to the barrel tip:

var b = BulletScene.instantiate()
get_tree().current_scene.add_child(b)
b.global_position = $Muzzle.global_position

Now a designer moves the barrel tip by dragging in the editor — no code change. See Making Bullets.

Patrol endpoints. Drop PointA and PointB, drag them where you want the enemy to walk. Full build in Patrol Enemies.

Player start / respawn point. Drop a SpawnPoint marker in each level:

player.global_position = $SpawnPoint.global_position

Used by Health and Lives and Hazards.

Camera anchors, door destinations, checkpoints — anywhere you'd otherwise hardcode Vector2(347, 812) and regret it.

💡Make markers children of the level, not the moving thing

A patrol marker parented to the enemy travels with the enemy, so the enemy chases a target it can never reach. Parent patrol and spawn markers to the level root. (Muzzle markers are the exception — those should ride along with the gun.)

#Two useful Node2D methods

look_at(target.global_position)                       # point at something
var angle = global_position.angle_to_point(target)    # get the angle without turning
var dist  = global_position.distance_to(target)       # how far away
var dir   = global_position.direction_to(target)      # normalized Vector2 toward it

direction_to() is the one line behind Homing Enemies and aimed shots in Making Bullets.
