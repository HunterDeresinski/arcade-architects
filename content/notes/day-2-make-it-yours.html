#The big idea

You already have a working game. A remix means: keep what works, change what's yours. Most of game development is changing numbers and rules in something that already runs — not writing from a blank page.

A good first instinct: change one number, press Play, see what happened. That loop — tweak, run, observe — is how you'll learn the engine faster than any tutorial can teach you.

#Warm-Up: Read Your Own Code

Open your player.gd from yesterday. Before you change anything, read it.

  1. Find the line @export var speed = 400. What does 400 mean? (Answer: pixels per second.)
  2. Change speed to 1000. Press F5 to run. What changed?
  3. Change speed to 100. Run again. Try to survive. Change it back to something that feels good — speed = 600 is a nice sweet spot, or whatever you like.
  4. Find score += 1 inside _on_score_timer_timeout(). Change it to score += 10. Run and watch the score.
  5. Find the MobTimer node in your Main scene. In the Inspector, change Wait Time from 0.5 to 0.2. Run — how does it feel?
💡You just did game design

Those three changes — speed, score value, and spawn rate — are the same knobs that professional game designers turn. The difference is they have spreadsheets. You have F5.

#Mini-lesson 1 (9:15–9:30): Swapping a Sprite

You don't have to use the grey player or the bug enemies. Here's how to swap:

  1. In the FileSystem dock, find a new image — or drag one in from the Asset Resources folder on the shared drive.
  2. Select AnimatedSprite2D under your Player in the Scene dock.
  3. In the Inspector, open Sprite Frames → click on the walk animation.
  4. Click the trash icon to clear the old frames. Drag your new images in.
  5. Repeat for the up animation if you want a side view.
  6. Press F5 — your player should now be whatever you dragged in.
  7. Same steps work for the enemies: open mob.tscn from the FileSystem dock and swap the frames in its AnimatedSprite2D (it has three animations — fly, swim, walk — replace whichever ones you want).
⚠️Image size matters

If your new sprite looks tiny or huge, select AnimatedSprite2D and adjust Scale under Transform in the Inspector. (1.0, 1.0) = original size. (0.5, 0.5) = half size.

#Mini-lesson 2 (9:30–9:45): Variables as Dials

Variables are the knobs of your game. Open main.gd and add one at the top:

@export var score_per_second = 1

Then down in _on_score_timer_timeout(), replace score += 1 with:

score += score_per_second

Now save and go back to the Inspector with Main selected — you'll see Score Per Second right there. You can change it without touching code. Change it to 5, run the game.

This is the @export keyword at work — see GDScript Basics for more.

#Mini-lesson 3 (9:45–10:00): Adding a Rule with if

Want to add lives? Find the _on_body_entered function in player.gd:

func _on_body_entered(_body):
	hide()
	hit.emit()
	$CollisionShape2D.set_deferred("disabled", true)

You could add a lives variable in main.gd:

var lives = 3

And in game_over() in main.gd, subtract a life instead of ending immediately:

func game_over():
	lives -= 1
	if lives <= 0:
		$ScoreTimer.stop()
		$MobTimer.stop()
	else:
		$Player.start($StartPosition.position)

See GDScript Basics for how if works and Area2D for more collision ideas.

#How to do the common changes

New background color: In your Main scene, add a ColorRect as the first child (drag it to the top of the tree in the Scene dock). In the Inspector, set Color to whatever you want. Then click Layout → Anchors Preset → Full Rect so it fills the screen. See Scenes and Nodes.

A pickup item (Area2D that gives points):

  1. Scene → New Scene → add Area2D as root → rename it Pickup.
  2. Ctrl+A → add Sprite2D (drag in your pickup image) and CollisionShape2D (give it a shape in the Inspector — an empty CollisionShape2D detects nothing).
  3. Attach a script to Pickup:
extends Area2D

signal collected

func _on_body_entered(_body):
	collected.emit()
	queue_free()
  1. With Pickup selected → Signals tab → double-click body_entered → Connect (this wires up _on_body_entered, already in the script above). Save as pickup.tscn.
  2. Open main.tscn and drag pickup.tscn from the FileSystem dock into the scene. Position it in the viewport.
  3. Select the Pickup instance → Signals tab → double-click collected → connect it to Main. In the new function in main.gd:
func _on_pickup_collected():
	score += 50
	$UI/ScoreLabel.text = "Score: " + str(score)  # only if you built Day 1's HUD stretch goal
  1. Press F5 and walk into it — it should vanish and the score should jump. See Area2D for the full pattern.

Speed up over time:

  1. Select Main in main.tscn → Ctrl+A → add a Timer → rename it SpeedUpTimer → in the Inspector set Wait Time to 5 and check Autostart.
  2. Select SpeedUpTimer → Signals tab → double-click timeout → connect it to Main. In the new function in main.gd:
func _on_speed_up_timer_timeout():
	$Player.speed += 50
  1. Press F5 — every 5 seconds the player gets faster. (To make mobs come faster instead, change $MobTimer.wait_time the same way.) See Spawning and Timers.

Add background music:

  1. Select Main → Ctrl+A → add an AudioStreamPlayer → rename it Music.
  2. In the Inspector, drag a .ogg audio file from Asset Resources onto the Stream property.
  3. Enable Autoplay in the Inspector, then press F5 — music should start with the game.
  4. See AudioStreamPlayer for loop settings.

Add a death sound:

  1. Select Main → Ctrl+A → add another AudioStreamPlayer → rename it DeathSound.
  2. Drag a short .wav sound effect onto its Stream property. Leave Autoplay off — this one is triggered from code.
  3. In main.gd, play it inside game_over():
func game_over():
	$ScoreTimer.stop()
	$MobTimer.stop()
	$DeathSound.play()   # NEW
  1. Press F5 and get hit — you should hear it the moment a mob touches you. See AudioStreamPlayer for making your own sound in jsfxr.

Add a win condition (reach a score and win):

  1. In main.gd, find _on_score_timer_timeout() and add a check after the score goes up:
func _on_score_timer_timeout():
	score += 1
	if score >= 100:   # NEW — pick your own winning score
		win()
  1. So the win can clear leftover enemies, put mobs in a group: open mob.tscn → select the root Mob node → Node dock (next to Inspector) → Groups tab → type mobs → Add.
  2. Add a win() function right below game_over() in main.gd — it's the same shape, just happier:
func win():
	$ScoreTimer.stop()
	$MobTimer.stop()
	get_tree().call_group("mobs", "queue_free")   # clears every node in the "mobs" group
	$UI/ScoreLabel.text = "You win!"   # only if you built Day 1's HUD stretch goal
  1. Press F5 and survive to 100 — mobs should vanish and the game should stop. Tune the number until winning feels earned but reachable in under 3 minutes.

Add a second enemy type:

  1. In the FileSystem dock, right-click mob.tscn → Duplicate → name it mob2.tscn.
  2. Open mob2.tscn and make it different: swap the sprite frames (same steps as Mini-lesson 1), or make it bigger via Scale in the Inspector.
  3. In main.gd, add a second scene slot at the top, next to the existing one:
@export var mob_scene: PackedScene
@export var mob_scene_2: PackedScene   # NEW
  1. Select Main in the Scene dock — in the Inspector, drag mob2.tscn onto the new Mob Scene 2 slot (same move as Day 1 with mob.tscn).
  2. In _on_mob_timer_timeout(), replace the first line so each spawn flips a coin:
var mob
if randf() < 0.5:
	mob = mob_scene.instantiate()
else:
	mob = mob_scene_2.instantiate()
  1. Press F5 — roughly half the spawns should be your new enemy. Change 0.5 to make one type rarer.

#Starter scaffold (optional) — "One-Button Flap"

Blank projects are hard to start. If you want concrete first steps instead of a blank page, here's a minimal one-button game — it reuses the exact same node types and spawning pattern as Dodge the Creeps, just wired differently. Skip this entirely if you already have your own idea.

1. The Player (falls with gravity, one button makes it rise)

  1. New Scene → add Area2D as root → rename Player.
  2. Ctrl+A → add Sprite2D or AnimatedSprite2D (drag in any sprite) and CollisionShape2D (New CapsuleShape2D).
  3. Attach a script to Player:
extends Area2D

@export var flap_strength = -300
@export var gravity = 800
var velocity = 0.0

func _physics_process(delta):
	velocity += gravity * delta
	if Input.is_action_just_pressed("ui_accept"):   # Space bar or Enter
		velocity = flap_strength
	position.y += velocity * delta

func _on_area_entered(_area):
	get_tree().reload_current_scene()
  1. In the Scene dock, select Player → Signals tab → double-click area_entered → Connect (this wires up _on_area_entered, already in the script above).
  2. Save as player.tscn. Press F6 — Space should make the shape rise, then fall back down under gravity.

2. The Obstacle (drifts left, deletes itself off-screen)

  1. New Scene → Area2D as root → rename Obstacle → add Sprite2D + CollisionShape2D.
  2. Attach a script:
extends Area2D

@export var speed = 200

func _process(delta):
	position.x -= speed * delta
	if position.x < -50:
		queue_free()
  1. Save as obstacle.tscn.

3. The Main scene (spawns obstacles on a timer — same pattern as Day 1's MobTimer)

  1. New Scene → plain Node → rename Main. Instance player.tscn as a child.
  2. Add a Timer child → rename ObstacleTimer → Wait Time 1.5 → Autostart on.
  3. Attach a script to Main:
extends Node

@export var obstacle_scene: PackedScene

func _on_obstacle_timer_timeout():
	var obstacle = obstacle_scene.instantiate()
	obstacle.position = Vector2(600, randf_range(100, 600))
	add_child(obstacle)
  1. With Main selected, drag obstacle.tscn onto the Obstacle Scene slot in the Inspector (same move as dragging mob.tscn onto Main on Day 1).
  2. Select ObstacleTimer → Signals tab → connect timeout to Main.
  3. Press F6 — obstacles should drift in from the right on a loop; touching one restarts the scene.

From here it's the same "action + tension + failure state" formula as everything else this week — swap the sprite, change gravity/flap_strength/speed until it feels right, and it's your game.
