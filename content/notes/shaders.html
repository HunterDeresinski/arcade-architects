Difficulty: ⭐⭐⭐⭐ hard · Camp verdict: ⚠️ copy-paste only · Do instead: Tweens, Particles, Lights and CanvasModulate

#What it is

Small programs that run on the graphics card, once per pixel. They're how you get a white flash on hit, water ripples, dissolve effects, outlines, screen distortion, and CRT scanlines.

Written in a separate language (Godot Shading Language, close to GLSL), with its own math and its own mental model.

#Why not this week

Shaders are a whole second language on top of GDScript, and the debugging story is bad — a mistake usually produces a blank screen or a pink rectangle rather than an error message pointing at a line. A student who's still getting comfortable with if statements will not have a good time.

The bigger issue is opportunity cost. Almost everything a camp game wants from a shader has a non-shader answer that takes five minutes: modulate for a tint flash, Particles for effects, Lights and CanvasModulate for mood, Tweens for motion.

#The exception: copy-paste a hit flash

If a team wants the white-flash-on-hit effect specifically, hand them this. Don't teach it — hand it over.

Create a new Shader resource on the sprite's Material slot:

shader_type canvas_item;

uniform float flash_amount : hint_range(0.0, 1.0) = 0.0;
uniform vec4 flash_color : source_color = vec4(1.0);

void fragment() {
	vec4 tex = texture(TEXTURE, UV);
	COLOR = mix(tex, vec4(flash_color.rgb, tex.a), flash_amount);
}
func flash():
	$Sprite.material.set_shader_parameter("flash_amount", 1.0)
	await get_tree().create_timer(0.08).timeout
	$Sprite.material.set_shader_parameter("flash_amount", 0.0)

This looks noticeably better than modulate = Color.WHITE because it preserves the sprite's silhouette instead of washing it out. It's the one shader worth the trouble in a camp game — great for Melee Attacks and Health and Lives.

#Where to send a curious student

  • godotshaders.com — a large library of free, ready-to-paste shaders. Genuinely the best resource, and using someone else's shader is a legitimate skill.
  • The Book of Shaders (thebookofshaders.com) — the classic gentle introduction, though it's not Godot-specific.
  • Godot docs → Shading section.

Encourage using shaders from the library now, and writing them later. Downloading a water shader and tweaking its parameters is a real, satisfying skill that requires none of the math.

#What to say in the moment

"You can absolutely use shaders — grab one from godotshaders.com and change the numbers. Writing your own is a summer project; it's a whole second language and the error messages are unhelpful. What effect are you actually going for? There's probably a five-minute version."
