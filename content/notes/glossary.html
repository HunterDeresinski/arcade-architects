#Godot & engine terms

Node — one building block that does one job (show a picture, play a sound). Scenes and Nodes

Scene — a tree of nodes saved together as a .tscn file. Can be reused inside other scenes. Scenes and Nodes

Instance / Instancing — a copy of a scene placed into the game. Build one Enemy scene, spawn 50 instances. Spawning and Timers

Root node — the top node of a scene; everything else hangs under it.

Inspector — the right-side panel showing the selected node's properties. Godot Editor Tour

Main scene — the screen that loads first when the game runs. Godot Editor Tour

res:// — "from the project's root folder," used in file paths. Scene Switching

#Code terms (GDScript)

GDScript — Godot's Python-like coding language. GDScript Basics

Variable — a named container for a value (var speed = 400). GDScript Basics

Function — a named block of code you can run (func jump():). GDScript Basics

@export — marks a variable so it shows in the Inspector for easy tweaking. GDScript Basics

_ready() — runs once when a node enters the game. GDScript Basics

_process(delta) — runs every frame (~60×/sec). delta = time since last frame. GDScript Basics

_physics_process(delta) — like _process but at a steady rate; use it for movement. Movement and Input

Vector2 — a pair of numbers (x, y): a position or direction on screen. Movement and Input

queue_free() — deletes a node from the game (use for grabbed coins, dead enemies). Area2D

Error — red text in the Output panel when code can't run. Read the first line; it usually names the line number. Godot Editor Tour

#Node types you'll use

CharacterBody2D — a thing that moves and bumps into stuff (the player). Movement and Input

Area2D — detects overlaps (hits, pickups). Needs a CollisionShape2D. Area2D

CollisionShape2D — defines the shape an Area2D detects. No shape = detects nothing. Area2D

Timer — waits, then fires a timeout signal. Spawning and Timers

Label — shows text on screen (score, messages). Score and UI

CanvasLayer — keeps UI pinned to the screen instead of moving with the world. Score and UI

AudioStreamPlayer — plays a sound or music. AudioStreamPlayer

Signal — a node's announcement that something happened ("doorbell"); other nodes connect and react. Signals

#Design & process terms

Tiny game — a short game with tight constraints, built fast around one idea. The Tiny Game Rules

Core loop — what the player does over and over, every few seconds. Tiny Game Design

Constraint — a rule you design within (one screen, one button). Sparks ideas. Constraint Cards

Scope — how big your game is. Too much scope = unfinished. "Idea ÷ 4." Tiny Game Design

Prototype — a rough, fast version (even on paper) to test if it's fun. Paper Prototyping

MVP — Minimum Viable Product: the smallest playable version. MVP Checklist

Playtest — watching someone play to find problems. Playtesting

Juice — small feedback (shake, sound, pop) that makes a game feel good. Polish only. Tiny Game Design

Feature freeze — the point where you stop adding and only fix/polish. Day 5 - Polish and Showcase

Export / Build — turning your project into something others can play. Exporting Your Game
