#The big idea

A game in Godot is a tree of nodes. Each node does one small job — show a picture, detect a hit, play a sound. You snap them together into scenes, give them scripts, and the game runs. That's the whole engine. See Scenes and Nodes.

Today we follow a tutorial step-by-step. Following first, inventing second. Tomorrow you'll change everything.

#Welcome: What is a Tiny Game?

Play 2–3 tiny games together on the projector (good picks: anything from a Pico-8 jam, a classic arcade game, a simple web game). Ask after each one: "What's the one idea in this game?"

Introduce the Tiny Game Rules (post these on the wall all week):

  • One core idea. If you can't say it in one sentence, it's too big.
  • Playable in under 3 minutes.
  • Done is better than perfect.

Then tell students what they'll build today: Dodge the Creeps — a character you move, enemies that fly in, survive as long as you can.

#Godot Tour + Project Setup

#Get oriented in the editor

Open Godot 4. Walk students through the 5 panels:

  • Scene dock (top left) — your node tree
  • FileSystem dock (bottom left) — your project files
  • Viewport (center) — where you see and build the game
  • Inspector (right) — properties of whatever is selected
  • Output (bottom center) — where errors and print() messages appear → Godot Editor Tour

#Set up the project

  1. Launch Godot → New Project → choose a folder → Create.
    1. Download the assets form Here
  3. Click Compatibility
  4. Download the starter assets from the GwG shared drive — direct link (folder: Arcade Architects Assets). Move the art/ and fonts/ folders into your project folder.
  5. Once created go to Project → Project Settings → Display → Window:
    • Set Viewport Width: 480
    • Set Viewport Height: 720
  • In the same window, scroll down to Stretch:
    • Mode: canvas_items
    • Aspect: keep
  1. Close Project Settings.
🗒️Why 480×720?

It's a tall phone-style screen. All the tutorial's layout and mob paths are built for this size — changing it now breaks things later.

#Part 1: Build the Player

Goal by end of this block: a character on screen that moves with arrow keys.

#Step 1: The Player scene (10 min)

  1. In the Scene dock, click Other Node → choose Area2D (You can search the bar at the top) → rename it Player (You can click on it and press F2 to start to rename).
  2. Click the Group icon in the toolbar (the icon that looks like a box with children) so clicking child nodes in the viewport selects the root.
  3. Save: Scene → Save Scene (Ctrl+S) as player.tscn.

See Scenes and Nodes for why Area2D is used here.

#Step 2: Add animations (15 min)

  1. With Player selected, press Ctrl+A → add AnimatedSprite2D.
  2. In the Inspector, click [empty] next to Sprite Frames → SpriteFrames. Click the new resource to open the SpriteFrames panel at the bottom.
  3. Rename the default animation to walk (you can double click it to rename.
  4. Click Add Animation (Or ctrl + n) → name it up.
  5. Drag frames from the FileSystem into each animation:
    • walk: playerGrey_walk1.png and playerGrey_walk2.png
    • up: playerGrey_up1.png and playerGrey_up2.png
  6. Set AnimatedSprite2D Scale to (0.5, 0.5) in the Inspector (under Transform).

#Step 3: Add a collision shape (5 min)

  1. With Player still selected, Ctrl+A → add CollisionShape2D.
  2. In the Inspector, click [empty] next to Shape → New CapsuleShape2D.
  3. Drag the orange handles in the viewport to resize the capsule to match the sprite roughly.

#Step 4: Set up the Input Map (5 min)

  1. Project → Project Settings → Input Map tab.
  2. Add four actions (type each name, click Add, click the +, press the key, click OK):
    • move_right → Right arrow or D
    • move_left → Left arrow or A
    • move_up → Up arrow or W
    • move_down → Down arrow or S
  3. Close Project Settings.

#Step 5: Attach the player script (15 min)

  1. Click Player in the Scene dock → click the Attach Script icon → Create. You get player.gd. Replace the contents with:
extends Area2D

signal hit

@export var speed = 400
var screen_size

func _ready():
	screen_size = get_viewport_rect().size
	hide()

func _process(delta):
	var velocity = Vector2.ZERO
	if Input.is_action_pressed("move_right"):
		velocity.x += 1
	if Input.is_action_pressed("move_left"):
		velocity.x -= 1
	if Input.is_action_pressed("move_down"):
		velocity.y += 1
	if Input.is_action_pressed("move_up"):
		velocity.y -= 1

	if velocity.length() > 0:
		velocity = velocity.normalized() * speed
		$AnimatedSprite2D.play()
	else:
		$AnimatedSprite2D.stop()

	position += velocity * delta
	position = position.clamp(Vector2.ZERO, screen_size)

	if velocity.x != 0:
		$AnimatedSprite2D.animation = "walk"
		$AnimatedSprite2D.flip_v = false
		$AnimatedSprite2D.flip_h = velocity.x < 0
	elif velocity.y != 0:
		$AnimatedSprite2D.animation = "up"
		$AnimatedSprite2D.flip_v = velocity.y > 0

func _on_body_entered(_body):
	hide()
	hit.emit()
	$CollisionShape2D.set_deferred("disabled", true)

func start(pos):
	position = pos
	show()
	$CollisionShape2D.disabled = false
💡Save!

Remember to Ctrl + S every single time you are done editing a script. This way you wont lose progress or have unexpected behavior!

  1. Back in the Scene dock, select Player → open the Signals tab (next to Inspector)
  2. Double-click body_entered → leave defaults → Connect. Godot creates _on_body_entered() — it's already in the script above.
💡Test it now

Press F6 (Run Current Scene). The player is hidden at start — that's correct. You can temporarily remove hide() in _ready() to see it move. Arrow keys should move in all directions. Close the window when done.

See Movement and Input and GDScript Basics for how the code works.

#Part 2: Build the Mob

Goal: an enemy scene ready to be spawned.

#Step 1: Mob scene setup (15 min)An

  1. Scene → New Scene Or Ctrl + N.

  2. Add a RigidBody2D (Inside other again) as root → rename to Mob.

  3. Add these three children (Remember, Ctrl+A):

    • AnimatedSprite2D
    • CollisionShape2D
    • VisibleOnScreenNotifier2D

  4. Select Mob (root) → click the Group icon in the toolbar.

  5. With Mob selected in the Inspector:

    • Set Gravity Scale to 0 (so it doesn't fall).
    • Under Collision, find the Mask row and uncheck layer 1 (mobs won't collide with each other).

#Step 2: Mob animations (10 min)

  1. Select AnimatedSprite2D → click the SpriteFrames property → New SpriteFrames. Create 3 animations:
    • fly: enemyFlyingAlt_1.png + enemyFlyingAlt_2.png
    • swim: enemySwimming_1.png + enemySwimming_2.png
    • walk: enemyWalking_1.png + enemyWalking_2.png
    • Set Animation Speed to 3 for each one.
  2. Set AnimatedSprite2D Scale to (0.75, 0.75).
  3. Select CollisionShape2D → New CapsuleShape2D → set Rotation to 90 under Transform.

#Step 3: Mob script (5 min)

  1. Attach a script to Mob. Replace contents:
extends RigidBody2D

func _ready():
	var mob_types = Array($AnimatedSprite2D.sprite_frames.get_animation_names())
	$AnimatedSprite2D.animation = mob_types.pick_random()
	$AnimatedSprite2D.play()

func _on_visible_on_screen_notifier_2d_screen_exited():
	queue_free()
  1. Select VisibleOnScreenNotifier2D → Signals tab → double-click screen_exited → Connect.
  2. Save scene as mob.tscn.

See Spawning and Timers for how spawning works.

#Part 3: The Main Scene

Goal: a playable game — mobs spawn, player dies on touch.

#Step 1: Build the Main scene (10 min)

  1. Scene → New Scene → add a plain Node (not Node2D) → rename to Main.
  2. Right Click on player.tscn and click the Instantiate icon (chain link) → select player.tscn. Player is now a child of Main.
  3. Add these child nodes one at a time:
Node typeNameSettings
Marker2DStartPositionMove to center-bottom of screen: (240, 450)
TimerMobTimerWait Time: 0.5
TimerScoreTimerWait Time: 1
TimerStartTimerWait Time: 2, One Shot: On
Path2DMobPath(leave empty for now)
  • It should look like this at the end

  1. Select MobPath → add a child PathFollow2D → rename to MobSpawnLocation.

#Step 2: Draw the mob path (5 min)

  1. Select MobPath in the Scene dock.
  2. In the toolbar at the top of the viewport, click Add Point.
💡Quick Tip

You can hover over buttons to see the name of them!

  1. Enable Snap to Grid (magnet icon).
  2. Click to place 4 points clockwise around the screen edges — top-left, top-right, bottom-right, bottom-left.
    • The blue lines inside the 2D Tab is how you can see the edges
  3. Click Close Curve to connect the last point back to the first.
⚠️Draw clockwise

If the path goes counter-clockwise, mobs will spawn pointing the wrong direction.

#Step 3: Main script (20 min)

  1. Attach a script to Main:
extends Node

@export var mob_scene: PackedScene
var score

func _ready():
	pass

func game_over():
	$ScoreTimer.stop()
	$MobTimer.stop()

func new_game():
	score = 0
	$Player.start($StartPosition.position)
	$StartTimer.start()

func _on_score_timer_timeout():
	score += 1

func _on_start_timer_timeout():
	$MobTimer.start()
	$ScoreTimer.start()

func _on_mob_timer_timeout():
	var mob = mob_scene.instantiate()
	var mob_spawn_location = $MobPath/MobSpawnLocation
	mob_spawn_location.progress_ratio = randf()
	mob.position = mob_spawn_location.position
	var direction = mob_spawn_location.rotation + PI / 2
	direction += randf_range(-PI / 4, PI / 4)
	mob.rotation = direction
	var velocity = Vector2(randf_range(150.0, 250.0), 0.0)
	mob.linear_velocity = velocity.rotated(direction)
	add_child(mob)
  1. With Main selected in the Scene dock, drag mob.tscn from the FileSystem onto the Mob Scene slot in the Inspector.
  2. Select Player (child of Main) → Signals tab → double-click hit → type game_over in the Receiver Method box → Connect.
  3. Select MobTimer → Signals tab → connect timeout to Main (creates _on_mob_timer_timeout).
  4. Repeat for ScoreTimer and StartTimer.
  5. Temporarily add new_game() to _ready(), click Play, select main.tscn as the Main Scene. Test: player spawns, mobs come in, player hides when hit.
  6. Remove new_game() from _ready() (change it back to pass).

Save main.tscn.

#Open Studio — Stretch Goals (for students who finish early)

Work through them in order. Each one builds directly on the exact main.tscn / main.gd / player.tscn you already built in Parts 1–3, so the node names and code below should match what's already in your project. Nobody is expected to reach all five — get as far as you get.

#1. Add the HUD (score display + start button)

Goal: a Label that shows the score, and a Start button that begins the game.

  1. In the Scene dock, select Main → Ctrl+A → add CanvasLayer → rename UI (keeps the UI pinned to the screen instead of scrolling with the game world).
  2. With UI selected, Ctrl+A → add Label → rename ScoreLabel. Drag it to the top-left corner in the viewport. In the Inspector, set Text to Score: 0 as a placeholder.
  3. With UI selected again, Ctrl+A → add Button → rename StartButton. Set its Text to Start in the Inspector and center it in the viewport.
  4. Open main.gd and update it — everything marked # NEW below is the only thing that's different from your Part 3 script:
extends Node

@export var mob_scene: PackedScene
var score

func _ready():
	$UI/StartButton.pressed.connect(_on_start_button_pressed)  # NEW

func game_over():
	$ScoreTimer.stop()
	$MobTimer.stop()
	$UI/StartButton.show()  # NEW — let the player start again

func new_game():
	score = 0
	$UI/ScoreLabel.text = "Score: 0"  # NEW
	$Player.start($StartPosition.position)
	$StartTimer.start()

func _on_score_timer_timeout():
	score += 1
	$UI/ScoreLabel.text = "Score: " + str(score)  # NEW

func _on_start_timer_timeout():
	$MobTimer.start()
	$ScoreTimer.start()

func _on_mob_timer_timeout():
	var mob = mob_scene.instantiate()
	var mob_spawn_location = $MobPath/MobSpawnLocation
	mob_spawn_location.progress_ratio = randf()
	mob.position = mob_spawn_location.position
	var direction = mob_spawn_location.rotation + PI / 2
	direction += randf_range(-PI / 4, PI / 4)
	mob.rotation = direction
	var velocity = Vector2(randf_range(150.0, 250.0), 0.0)
	mob.linear_velocity = velocity.rotated(direction)
	add_child(mob)

func _on_start_button_pressed():  # NEW
	$UI/StartButton.hide()
	new_game()
  1. Ctrl+S to save the script, then delete the temporary new_game() call in _ready() from Part 3 if you still have it — the Start button calls it now.
  2. Press F6 — the Start button should appear, hide when clicked, and the score should count up in the corner.

See Score and UI for more on Label and Button basics.

#2. Add background music + a death sound

  1. Drag a music file (.ogg) and a short sound effect (.wav) into the FileSystem dock — grab free ones from Asset Resources, or make a quick "hit" sound in jsfxr.
  2. Select Main → Ctrl+A → add AudioStreamPlayer → rename Music. In the Inspector, drag your music file onto Stream, then check Autoplay.
  3. Select Main again → Ctrl+A → add another AudioStreamPlayer → rename DeathSound. Drag your sound effect onto its Stream property. Leave Autoplay off — this one triggers from code, not automatically.
  4. In main.gd, play the death sound inside game_over():
func game_over():
	$ScoreTimer.stop()
	$MobTimer.stop()
	$DeathSound.play()   # NEW
	$UI/StartButton.show()
  1. Ctrl+S, then F6 — music should start automatically, and you should hear the death sound the moment a mob touches you.

See AudioStreamPlayer for looping music and making your own sounds with jsfxr.

#3. Add a background color

  1. Select Main in the Scene dock → Ctrl+A → add ColorRect.
  2. Drag it to the very top of Main's children list, above Player — nodes draw in list order, so it has to be first or it'll cover everything else on screen.
  3. With the ColorRect selected, in the Inspector under Layout, click Anchors Preset → Full Rect so it stretches to fill the screen at any size.
  4. Under CanvasItem → Color, pick a background color.
  5. Press F6 and confirm it's sitting behind the player and mobs, not on top of them.

#4. Export the game

Full walkthrough (with three different options) is in Exporting Your Game. Short version: Project → Export → Add… → pick a preset → Export Project. First time exporting, Godot will also ask you to download export templates — that needs internet, so do it now rather than at the showcase.

#5. Speed things up

  1. Select Player in the main.tscn scene tree (it's the instanced child under Main, not the standalone player.tscn) → in the Inspector, find Speed under Script Variables → change it from 400 to something like 600 or 800.
  2. Select MobTimer (child of Main) → in the Inspector, change Wait Time from 0.5 to 0.3 — mobs will spawn more often.
  3. Press F6 after each change and see how it feels. This "tweak, run, observe" loop is exactly what you'll be doing all day tomorrow.

#When you get stuck

  • Red text at the bottom (Output panel)? Read the first line — it usually names the file and line number.
  • Nothing happens when I press Play? Did you set a Main Scene? Did you connect the signals?
  • It worked a second ago and now it doesn't? Undo (Ctrl+Z) back to when it worked, then redo one step at a time.
  • "Invalid get index" error? A $NodeName path doesn't match the actual node name — check spelling exactly.
  • Totally lost? Find your spot on the checklist and raise your hand.
