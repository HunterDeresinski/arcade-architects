"I want to build a thing — how?" Each note is a complete build with copy-paste Godot 4 code. This is the page to hand a student on Day 3 when their team is deciding what their game is.

Moving PlatformsSliding platforms, elevators, falling platforms
Bouncing BallPong, Breakout, anything that ricochets

#Things in the world

NoteBuild
CollectablesCoins, gems, hearts. The best first mechanic to add to any game
ObstaclesWalls and crates — turning an open field into a level
HazardsLava, spikes, saw blades
Doors and KeysLocked doors, keys, pressure plates, level exits

#Making it a real game

NoteBuild
Spawning and TimersEnemies that appear over time, difficulty that ramps
Score and UIScore, lives, messages on screen
Scene SwitchingTitle → Game → Game Over → restart
Autoload and GlobalKeeping score, lives, and settings alive across scene changes
Juice and Game FeelScreen shake, pops, flashes. Last, not first

#If you only have one day left

The shortest path from "it moves" to "it's a game" is three notes: Collectables (something to do) → Score and UI (feedback) → Scene Switching (a start and an end). Add Juice and Game Feel only once all three work.
