How to show score, lives, and messages on screen. UI = the text and buttons layered on top of the game.

#Showing text: the Label node

  1. Add a CanvasLayer node (keeps UI fixed on screen, not moving with the world).
  2. Under it, add a Label node. Type placeholder text, position it, set font size in the Inspector.
Main
├── Player
└── UI            (CanvasLayer)
	├── ScoreLabel  (Label)
	└── Message     (Label)

#Updating the score from code

extends Node

var score = 0

func _ready():
	update_score_label()

func add_points(amount):
	score += amount
	update_score_label()

func update_score_label():
	$UI/ScoreLabel.text = "Score: " + str(score)
  • str(score) turns the number into text so you can join it with "Score: ".
  • $UI/ScoreLabel = "the Label named ScoreLabel, inside UI."

#Score that ticks up over time

Use a repeating Timer (Wait Time 1.0):

func _on_score_timer_timeout():
	add_points(1)

#Receiving points from a coin

If your coin emits a collected signal (Area2D), connect it here:

func _on_coin_collected():
	add_points(10)

#Show a message (Game Over / You Win)

func show_message(text):
	$UI/Message.text = text
	$UI/Message.show()

func hide_message():
	$UI/Message.hide()

#A start/restart button

Add a Button node, connect its pressed signal (Signals):

func _on_start_button_pressed():
	get_tree().reload_current_scene()   # restart the game

More on screens and restarting: Scene Switching. To make a score survive closing the game, see High Scores That Persist.

💡Keep UI separate

Put all score/lives/message Labels under one CanvasLayer named UI. It keeps them pinned to the screen and easy to find.
