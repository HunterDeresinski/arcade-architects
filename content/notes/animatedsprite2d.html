How to make a character animate — walk cycles, idle bobs, flipping to face the direction of travel. This is the node the Day 1 player already uses; here's how to drive it yourself.

🗒️Related nodes

Sprite2D for a still image, AnimationPlayer for animating properties (position, rotation, fade) rather than frames.

#Setting it up

  1. In your Player scene, add an AnimatedSprite2D child (or use the existing one).
  2. Inspector → Sprite Frames → <empty> → New SpriteFrames, then click it. The SpriteFrames panel opens at the bottom.
  3. In the panel, the animation list starts with one animation named default. Double-click to rename it (idle), and use Add Animation (the paper icon) for more: walk, jump...
  4. Add frames to the selected animation:
    • Separate image files — drag the PNGs from the FileSystem dock into the frame strip.
    • One sprite sheet — click Add frames from Sprite Sheet (the grid icon), open the sheet, set how many columns/rows it has, then click the frames you want in order.
  5. Per-animation settings, left of the frame strip: speed (FPS — 5–10 fits chunky pixel art) and loop (on for idle/walk, off for one-shots like attack or death).
💡Test without running the game

Select an animation and press the ▶ in the SpriteFrames panel — it previews right in the editor.

#Playing animations from code

The script lives on the parent (the CharacterBody2D), reaching the sprite with $:

$AnimatedSprite2D.play("walk")   # start an animation (by its exact name)
$AnimatedSprite2D.stop()         # freeze on the current frame

play() on an already-playing animation does nothing — safe to call every frame.

#The standard pattern: match animation to movement

Add this at the end of _physics_process, after move_and_slide():

	# facing: flip the art when walking left
	if velocity.x < 0:
		$AnimatedSprite2D.flip_h = true
	elif velocity.x > 0:
		$AnimatedSprite2D.flip_h = false

	# which animation?
	if velocity.length() > 0:
		$AnimatedSprite2D.play("walk")
	else:
		$AnimatedSprite2D.play("idle")
  • flip_h = true mirrors the sprite horizontally — draw art facing right, get left for free. (flip_v exists for vertical.)
  • The elif (not else) matters: when standing still (velocity.x == 0), the sprite keeps facing its last direction instead of snapping right.
  • Exact-name gotcha: play("Walk") ≠ play("walk"). Typos here fail silently or error at runtime — copy the name from the SpriteFrames panel.

Platformer version (Platformer Physics) — air state wins over ground states:

	if not is_on_floor():
		$AnimatedSprite2D.play("jump")
	elif velocity.x != 0:
		$AnimatedSprite2D.play("walk")
	else:
		$AnimatedSprite2D.play("idle")

#One-shot animations (attack, death)

For non-looping animations, the animation_finished signal (Signals) fires when the last frame ends:

func die():
	$AnimatedSprite2D.play("death")
	await $AnimatedSprite2D.animation_finished
	queue_free()   # remove after the animation completes

Without the await, the node vanishes on frame 1 of its own death animation — a very common "my death animation doesn't play" ticket.

#Useful extras

$AnimatedSprite2D.animation            # name of the current animation ("walk")
$AnimatedSprite2D.is_playing()         # true / false
$AnimatedSprite2D.speed_scale = 2.0    # play everything at double speed

speed_scale is a fun Juice and Game Feel trick: speed up the walk cycle when the player has a speed power-up.

⚠️"My animation doesn't play" checklist

(1) Name matches exactly (case-sensitive). (2) The animation has more than one frame. (3) FPS isn't 0. (4) For one-shots: Loop is off and nothing calls play("idle") right after — the movement pattern above will stomp a one-shot unless you guard it.
