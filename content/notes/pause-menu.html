Difficulty: ⭐ easy · Payoff: ⭐⭐ solid · Time: 15 minutes

Press Escape, everything freezes, a menu appears. Small feature, and it's one of the clearest signals that a game is finished rather than a prototype. Builds on Label and CanvasLayer and Scene Switching.

#Godot pauses the whole tree for you

get_tree().paused = true

One line stops _process, _physics_process, Timers, animations, and input handling across the entire scene tree.

Which is the problem — it also freezes your pause menu, so nothing can unpause it. That's the soft-lock every team hits.

#The fix: Process Modes

Every node has Inspector → Process → Mode:

ModeBehaviour
Inheritsame as its parent (the default)
Pausablestops when paused — the normal game
When Pausedruns only when paused
Alwaysruns no matter what

Set your pause menu's CanvasLayer to Always (or When Paused). Now it keeps running while everything else is frozen.

#The scene

Main
├── Player, enemies, level...          ← all default (Pausable)
└── PauseLayer      (CanvasLayer)      ← Process Mode: ALWAYS
    ├── Dim          (ColorRect)        ← black, alpha ~0.6, full screen
    └── Panel        (Panel)
        ├── Title     (Label)  "PAUSED"
        ├── Resume    (Button)
        ├── Restart   (Button)
        └── Quit      (Button)

The Dim ColorRect behind the panel is the whole visual trick — it separates the menu from the frozen game underneath and takes ten seconds.

#The script

Put this on your Main scene (or on the PauseLayer itself):

extends Node2D

func _ready():
	$PauseLayer.hide()

func _unhandled_input(event):
	if event.is_action_pressed("ui_cancel"):     # Escape, free by default
		toggle_pause()

func toggle_pause():
	var paused = not get_tree().paused
	get_tree().paused = paused
	$PauseLayer.visible = paused

func _on_resume_pressed():
	toggle_pause()

func _on_restart_pressed():
	get_tree().paused = false                    # ALWAYS unpause before switching
	get_tree().reload_current_scene()

func _on_quit_pressed():
	get_tree().paused = false
	get_tree().change_scene_to_file("res://title.tscn")

Connect each Button's pressed signal (Label and CanvasLayer).

⚠️Unpause before you change scenes

get_tree().paused is not reset by loading a new scene. Forget the paused = false line and your restarted game loads permanently frozen, with no menu to unpause it. This is the single most common bug in this note.

#Use _unhandled_input, not _input

_unhandled_input only fires if no UI element already consumed the event, so a focused Button won't swallow your Escape key. It's the right choice for any global hotkey.

#Nice additions

Fade the dim panel in (Tweens) instead of snapping:

func toggle_pause():
	var paused = not get_tree().paused
	get_tree().paused = paused
	if paused:
		$PauseLayer.show()
		$PauseLayer/Dim.modulate.a = 0.0
		create_tween().tween_property($PauseLayer/Dim, "modulate:a", 0.6, 0.2)
	else:
		$PauseLayer.hide()

Tweens need Process Mode: Always on the node running them, or they freeze too.

Duck the music while paused (AudioStreamPlayer):

$Music.volume_db = -20 if paused else 0

Pause automatically when the window loses focus — genuinely useful at a showcase when someone walks away mid-game:

func _notification(what):
	if what == NOTIFICATION_APPLICATION_FOCUS_OUT and not get_tree().paused:
		toggle_pause()

Keyboard/controller navigation: click the Resume button → Inspector → Focus → Neighbour Top/Bottom to link the buttons, and call $PauseLayer/Panel/Resume.grab_focus() when the menu opens. Now the menu works on a gamepad (Two-Player and Gamepad).

#Also useful for

Same Process Mode trick, different content:

  • A game over overlay that freezes the action behind it
  • A level complete screen with a score tally
  • A cutscene or dialogue box that pauses gameplay (Dialogue and Text Boxes)
  • A settings panel — volume sliders, fullscreen toggle
