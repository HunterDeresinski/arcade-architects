Difficulty: ⭐ easy · Payoff: ⭐⭐ solid · Time: 10 minutes

Shows a picture. It's the most-used node in any 2D game and the core reference never gives it its own page — AnimatedSprite2D covers animation, and this covers the still image underneath.

#Setup

Add a Sprite2D, then drag an image from the FileSystem dock into the Inspector's Texture slot. Done.

Even faster: drag the image straight from the FileSystem dock into the 2D viewport and Godot creates the Sprite2D for you.

#The three you'll use constantly

Flipping to face the way you're moving:

if velocity.x != 0:
	$Sprite.flip_h = velocity.x < 0

Two lines, and your character stops moonwalking. Note the != 0 guard — without it the sprite snaps back to facing right whenever you stop.

Flashing when hit (Health and Lives):

$Sprite.modulate = Color.RED
await get_tree().create_timer(0.1).timeout
$Sprite.modulate = Color.WHITE

Fading out (Tweens):

create_tween().tween_property($Sprite, "modulate:a", 0.0, 0.4)

#Centered, and why your art is offset

Centered is on by default, so the node's position is the middle of the image. For a character standing on the ground it's often nicer to have the origin at their feet — then position is where they're standing, and scaling or flipping happens around the right spot.

Rather than unchecking Centered, set Offset to (0, -16) (half the sprite height). The origin moves to the feet without changing how anything else works.

This is the fix for "my collision shape doesn't line up with my sprite."

#Pixel art settings (do this once, it matters)

Pixel art looks blurry in Godot by default. Two fixes:

Per-project (recommended): Project → Project Settings → Rendering → Textures → Default Texture Filter → Nearest. Every sprite in the project is now crisp.

Per-texture: select the image in the FileSystem dock → Import tab → Filter off → Reimport.

Also set Project Settings → Display → Window → Stretch → Mode: canvas_items and Aspect: keep so the game scales cleanly to any window size — important for a projector on showcase day (Exporting Your Game).

#Region: one image, many sprites

Check Region → Enabled and set the Region Rect to show only a slice of a bigger image. Useful when your art came as one packed sheet and you want a single tile from it without cutting the file up.

For animation from a sheet, use Hframes / Vframes instead — tell the Sprite2D how many columns and rows the sheet has, then pick with frame:

$Sprite.hframes = 4
$Sprite.vframes = 2
$Sprite.frame = 3      # 0-indexed, reading left to right, top to bottom

That's a manual, no-resource way to swap art — handy for a tile variant or a damaged state.

#Sprite2D vs AnimatedSprite2D

UseWhen
Sprite2Da still image, or one you change occasionally in code
AnimatedSprite2Dframe-by-frame animation — walk cycles, idle loops
AnimationPlayeranimating properties (position, rotation, modulate) rather than frames

A Sprite2D plus a couple of Tweens handles a surprising amount of "animation" without any frames at all — squash on landing, spin on death, pulse on pickup.
