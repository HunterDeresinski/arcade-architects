How to paint a whole level — floors, walls, platforms — instead of dragging in fifty StaticBody2D walls one at a time. Tiles can carry their own collision, so the level is solid for free. Pairs with CharacterBody2D and Camera2D.

#The pieces

  • TileMapLayer — the node you paint on. One layer of tiles (add more TileMapLayer nodes for background/foreground).
  • TileSet — a resource that holds your tile images and their collision shapes. Lives inside the TileMapLayer's Inspector.
  • Atlas — one image containing many tiles in a grid (e.g. a 16×16-per-tile sheet). This is how most free tile art comes (Asset Resources).
🗒️TileMap vs TileMapLayer

Older tutorials use a node called TileMap — it's deprecated. In our Godot (4.6) use TileMapLayer. Everything works the same; one node per layer instead of one node with internal layers.

#Setup, step by step

1. Add the node. In your Main scene, add a child → TileMapLayer. Rename it Level.

2. Create the TileSet. With Level selected: Inspector → Tile Set → <empty> → New TileSet. Click it to expand and set Tile Size to match your art (e.g. 16×16 — check the asset pack's description).

3. Add your tile art. Two panels open at the bottom of the editor:

  • TileSet panel (bottom) — where you define tiles.
  • TileMap panel (bottom) — where you paint tiles.

Open the TileSet panel and drag your tilesheet PNG from the FileSystem dock into the left column. When Godot asks "Would you like to automatically create tiles in the atlas?" → Yes. It slices the image into tiles on its own.

4. Paint. Switch to the TileMap panel, click a tile to select it, then click/drag in the viewport to paint. Hold Right-click to erase. Rect tool (in the panel toolbar) fills big areas fast.

💡Painting quality of life
  • Hold Shift while clicking to draw a straight line of tiles.
  • Pick the eyedropper in the TileMap panel to grab a tile already painted in the level.
  • If the grid doesn't match your art (tiles look cut off), the Tile Size from step 2 is wrong.

#Making tiles solid (collision)

Painted tiles are just pictures until you give them physics:

  1. Select the Level node → Inspector → expand Tile Set.
  2. Physics Layers → Add Element. This creates physics layer 0 on the TileSet. Set its Collision Layer to your world layer (see CharacterBody2D) and clear its Mask.
  3. Open the TileSet panel (bottom) → click Select mode → click a tile that should be solid.
  4. In the tile's properties, expand Physics → Physics Layer 0. A drawing area appears — the default is a full square covering the tile. That's usually exactly what you want; click the tile and the square shape is added.
  5. Repeat for every solid tile (walls, ground). Leave decorations (grass, flowers, background) with no physics.

Now a CharacterBody2D with world in its mask stops on those tiles automatically. No walls to build, no script on the level at all.

⚠️"My player falls through the floor"

Check, in order: (1) Did you add a physics layer to the TileSet (step 2)? (2) Does the tile you painted with have a collision polygon (steps 3–5)? (3) Does the player's mask include the TileSet's collision layer? Painting with the one tile you forgot to give physics is the classic version of this bug.

#Placing tiles from code (optional)

You rarely need this, but for procedural stuff:

# on the TileMapLayer node
# set_cell(grid_position, source_id, atlas_coords)
set_cell(Vector2i(5, 3), 0, Vector2i(0, 0))   # place tile
erase_cell(Vector2i(5, 3))                      # remove tile

# convert between pixel space and grid space
var grid_pos = local_to_map(get_local_mouse_position())
var pixel_pos = map_to_local(grid_pos)
  • source_id — which atlas (0 if you only added one image).
  • atlas_coords — which tile within the sheet, in tile units: Vector2i(0, 0) is top-left.

#Multiple layers

Add more TileMapLayer nodes for depth — order in the scene tree = draw order (lower in the tree draws on top):

Main
├── Background   (TileMapLayer)  ← sky, distant scenery, no physics
├── Level        (TileMapLayer)  ← solid ground/walls, physics layer
└── Foreground   (TileMapLayer)  ← vines, overhangs drawn over the player
