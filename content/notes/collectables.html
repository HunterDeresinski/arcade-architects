Coins, gems, stars, hearts, keys — anything the player runs into and picks up. This is the single best first mechanic to add to a game. It takes about ten minutes, it works in every genre, and it instantly gives a game a reason to explore. Built on Area2D and Signals.

#The coin scene

Scene → New Scene → Other Node → Area2D. Name it Coin, save as coin.tscn.

Coin              (Area2D)      Layer: pickups, Mask: player
├── Sprite         (Sprite2D or AnimatedSprite2D)
├── Shape          (CollisionShape2D)  ← CircleShape2D
└── PickupSound    (AudioStreamPlayer)

Layers are from Collision Layers and Masks — the coin lives on pickups and watches player, so mobs can walk right over it.

💡Make the shape bigger than the sprite

A pickup radius slightly larger than the coin art makes collecting feel generous instead of fiddly. This is a real design decision, not laziness.

#The coin script

extends Area2D

signal collected(amount)

@export var value = 1

func _on_body_entered(body):
	if body.is_in_group("player"):
		collected.emit(value)
		queue_free()

Connect the Area2D's body_entered signal to this function (Signals).

  • @export var value shows up in the Inspector — drop a coin worth 1 and a gem worth 10 from the same scene by changing one number per instance. No second scene needed.
  • is_in_group("player") — put the player in a group via Node dock → Groups → player → Add. More robust than checking the name (Area2D explains why).
  • queue_free() deletes the coin so it disappears.

#Counting them: the group approach

The easiest way to keep score without wiring up signals for every coin. In your Main script:

extends Node2D

var score = 0

func _ready():
	for coin in get_tree().get_nodes_in_group("coins"):
		coin.collected.connect(_on_coin_collected)
	update_label()

func _on_coin_collected(amount):
	score += amount
	update_label()
	if get_tree().get_nodes_in_group("coins").size() <= 1:
		win()   # that was the last one

func update_label():
	$UI/ScoreLabel.text = "Coins: %d" % score

Add every coin to a group called coins: select the Coin in the coin scene → Node dock → Groups → coins. Every instance inherits it, so you can drag fifty coins into the level and they all wire themselves up. See Score and UI and Label and CanvasLayer.

⚠️Why <= 1 and not == 0

queue_free() doesn't remove the node until the end of the frame, so the coin that just fired the signal is still in the list when you count. Off-by-one "I collected them all but nothing happened" bugs live here.

#Making it feel good (do this, it takes 3 minutes)

A silent coin that blinks out is forgettable. Replace queue_free() with:

func _on_body_entered(body):
	if not body.is_in_group("player"):
		return
	collected.emit(value)
	$PickupSound.play()
	$Shape.set_deferred("disabled", true)   # can't be collected twice
	# pop and fade instead of vanishing
	var tween = create_tween().set_parallel()
	tween.tween_property(self, "scale", Vector2(1.6, 1.6), 0.25)
	tween.tween_property(self, "modulate:a", 0.0, 0.25)
	tween.tween_property(self, "position:y", position.y - 20, 0.25)
	await tween.finished
	queue_free()

The coin swells, floats up, fades out, and dings. Same three lines of tween work anywhere — see Tweens and Juice and Game Feel.

#A gentle idle bob (no code)

Select the Coin → add an AnimationPlayer → new animation idle, 1 second, Loop on and Autoplay on. Key position:y at 0s and 1s, and position:y - 6 at 0.5s. Now every coin in your game breathes. Coins that move catch the eye far better than coins that sit still.

Or in three lines of code:

func _ready():
	var t = create_tween().set_loops()
	t.tween_property($Sprite, "position:y", -6.0, 0.6).as_relative().set_trans(Tween.TRANS_SINE)
	t.tween_property($Sprite, "position:y", 6.0, 0.6).as_relative().set_trans(Tween.TRANS_SINE)

#Variations

A magnet — coins fly toward a nearby player:

func _physics_process(delta):
	var players = get_tree().get_nodes_in_group("player")
	if players.is_empty(): return
	var p = players[0]
	if global_position.distance_to(p.global_position) < 120:
		global_position = global_position.move_toward(p.global_position, 300 * delta)

A heart that heals — same scene, different script, wired to Health and Lives:

if body.is_in_group("player"):
	body.heal(1)
	queue_free()

A key — see Doors and Keys.

A powerup with a timer — grant an ability, then take it back:

if body.is_in_group("player"):
	body.speed *= 2
	await get_tree().create_timer(5.0).timeout
	body.speed /= 2

Note this one can't queue_free() immediately — it has to stay alive to undo itself. Hide the sprite and disable the shape instead, then free it after.

Coins that spawn over time — combine with Spawning and Timers.

A collectable that unlocks the exit — the win condition of half the games at showcase.
