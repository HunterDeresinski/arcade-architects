The nodes that put text and buttons on the screen. CanvasLayer pins things to the screen so they don't scroll with the world. Label shows text. For the score system built on top of these, see Score and UI.

#Always start with a CanvasLayer

A Label placed directly in the world will slide off screen the moment your Camera2D moves. A CanvasLayer draws on a separate layer that ignores the camera entirely.

Main
├── Player
├── TileMapLayer
└── UI              (CanvasLayer)   ← everything on-screen goes under here
    ├── ScoreLabel   (Label)
    ├── Hearts       (HBoxContainer)
    └── Message      (Label)

Rule: if the player should always see it, it goes under a CanvasLayer. Score, lives, timers, menus, pause screens.

#Label

Add a Label, type into Text in the Inspector, drag it into place.

$UI/ScoreLabel.text = "Score: " + str(score)
$UI/Message.show()
$UI/Message.hide()
$UI/ScoreLabel.modulate = Color.RED     # tint it
⚠️str() is not optional

"Score: " + score errors — you can't add a number to text. "Score: " + str(score) works. This is the single most common GDScript error of the week.

Two nicer ways to build the string:

$UI/ScoreLabel.text = "Score: %d" % score              # %d = whole number
$UI/TimeLabel.text  = "Time: %.1f" % time_left         # %.1f = one decimal
$UI/ScoreLabel.text = "Score: {0}".format([score])

#Making a Label readable

Default Labels are small, white, and vanish against a bright background. In the Inspector:

  • Theme Overrides → Font Sizes → Font Size — bump it to 32+.
  • Theme Overrides → Colors → Font Color — pick something that contrasts.
  • Theme Overrides → Constants → Outline Size = 4, then Colors → Font Outline Color = black. An outline makes text legible over any background. Do this once on every Label; it's the cheapest polish in the game.
  • Horizontal/Vertical Alignment — set to Center, then size the Label box, rather than nudging position by hand.

#Anchors: keeping UI in the corner

Select the Label → the Anchor Preset button in the toolbar (looks like a box with red pins). Pick Top Left for a score, Center for a "GAME OVER" message, Bottom Right for a timer. Anchored UI stays put no matter what resolution the game runs at — which matters on Friday when your game is on a projector instead of your laptop.

func update_hearts(lives):
	for i in $UI/Hearts.get_child_count():
		$UI/Hearts.get_child(i).visible = i < lives

#A pause menu

func _unhandled_input(event):
	if event.is_action_pressed("ui_cancel"):   # Escape, free by default
		get_tree().paused = not get_tree().paused
		$UI/PauseMenu.visible = get_tree().paused

For the menu to still work while paused, select the CanvasLayer → Inspector → Process → Mode → Always. Otherwise the pause freezes the pause menu too, and nothing can unpause it.
