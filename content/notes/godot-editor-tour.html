The Godot window has a few main areas. Learn these names — the rest of the week we'll say "drag it into the Scene dock" and you'll know where that is.

#The main areas

  • Scene dock (top-left) — the node tree of the scene you're editing. This is your game's structure. See Scenes and Nodes.
  • FileSystem dock (bottom-left) — every file in your project (images, sounds, scenes, scripts). Drag from here into your game.
  • Viewport (center) — where you see and arrange your game. Tabs at the top switch between 2D, 3D, Script, and AssetLib. We live in 2D and Script.
  • Inspector (right) — every property of the node you have selected: position, texture, speed, color. Click a node, edit it here.
  • Bottom panel — Output (messages + errors), Debugger, Audio. When something breaks, errors show here.

#The buttons you'll use constantly

  • ▶ Play (F5) — run the whole game (the main scene).
  • 🎬 Play Current Scene (F6) — run just the scene you're editing. Great for testing one piece.
  • ⏹ Stop (F8) — stop the running game.
  • ➕ in the Scene dock — add a new node.

#Set your main scene (do this once)

The first time you press Play, Godot asks which scene is the "main" one — the screen that shows when the game starts. Pick it. Change it later under Project → Project Settings → Application → Run → Main Scene.

#Saving

  • Save scene: Ctrl/Cmd + S. Save before you press Play, every time.
  • Each scene is its own .tscn file in the FileSystem dock.
💡If the layout ever looks wrong

Editor → Reset to default layout brings everything back. You didn't break anything.
