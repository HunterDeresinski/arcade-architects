How to shoot things — one reusable bullet scene, then two complete builds: a Space Invaders shooter (you shoot up) and a bullet-dodging boss (it shoots at you). Builds on Area2D and CharacterBody2D.

#Layer setup first

Set up the camp-wide layer names once, from Collision Layers and Masks. Bullets use layer 4 — bullets.

The whole trick of this note: a bullet's mask decides what it can hit. Both kinds of bullet sit on the same bullets layer; only the mask differs.

BulletLayerMask
Player's bulletbulletsmobs, obstacles
Enemy's bulletbulletsplayer, obstacles

Nothing else needs an if check — if the signal fires, it hit something it was allowed to hit.

💡Give every bullet a VisibleOnScreenNotifier2D

Bullets that fly off screen keep existing forever, and the game slowly grinds to a halt. One node, one signal, one line of cleanup — do it now, not when it breaks.

#The bullet scene (used by both examples)

New scene: Area2D root named Bullet, with three children:

Bullet          (Area2D)                    Layer: bullets, Mask: mobs
├── Sprite      (Sprite2D)
├── Shape       (CollisionShape2D)
└── Notifier    (VisibleOnScreenNotifier2D) ← auto-cleanup when off screen

Script on the root — connect both signals in this scene: the Bullet's own body_entered, and the Notifier's screen_exited (Signals):

extends Area2D

@export var speed = 750
var direction = Vector2.RIGHT   # whoever spawns the bullet sets this

func _ready():
	rotation = direction.angle()   # point the sprite the way it flies

func _process(delta):
	position += direction * speed * delta

func _on_body_entered(body):
	body.queue_free()   # kill the mob
	queue_free()        # remove the bullet

func _on_visible_on_screen_notifier_2d_screen_exited():
	queue_free()

Because the mask only includes mobs, body_entered never fires for the player or walls — no group checks needed. That's conditional collision doing the work for you. The Notifier prevents the classic "1,000 invisible bullets flying to infinity" slowdown.

Save as bullet.tscn.

#Example 1: Space Invaders (shoot straight up)

Aliens come down from the top; the player slides along the bottom and shoots up.

Input Map: add a shoot action (Space) next to move_left/move_right.

Player script (on a CharacterBody2D — horizontal only):

extends CharacterBody2D

@export var speed = 400
@export var bullet_scene: PackedScene   # drag bullet.tscn here in the Inspector

func _physics_process(delta):
	velocity.x = Input.get_axis("move_left", "move_right") * speed
	move_and_slide()

	if Input.is_action_just_pressed("shoot"):
		shoot()

func shoot():
	var bullet = bullet_scene.instantiate()
	bullet.global_position = global_position + Vector2(0, -30)  # spawn above the ship
	bullet.direction = Vector2.UP
	get_tree().current_scene.add_child(bullet)
  • Drag bullet.tscn into the bullet_scene slot in the Inspector — forgetting this is the #1 crash (instantiate() on null).
  • Vector2.UP — remember y is negative-up in 2D (Platformer Physics).
  • The + Vector2(0, -30) offset spawns the bullet at the ship's nose instead of its center, so it can't clip the shooter.
  • Bullets are added to the current scene, not the player — they keep flying even if the player dies.

The aliens: any descending mob on the mobs layer works — reuse the pattern from Spawning and Timers with direction = Vector2.DOWN. Bullet mask = mobs → bullets pop aliens, aliens ignore each other.

Fire-rate limit (optional) — hold to shoot, but not a laser hose. Add a Timer child named Cooldown (Wait Time 0.25, One Shot ✓):

	# replace the is_action_just_pressed check with:
	if Input.is_action_pressed("shoot") and $Cooldown.is_stopped():
		shoot()
		$Cooldown.start()

#Example 2: Boss that shoots at the player

A boss stands in one place, fires bullets aimed at wherever the player is, and the player dodges.

Enemy bullet variant. Duplicate the bullet scene (FileSystem → right-click bullet.tscn → Duplicate → boss_bullet.tscn) and change two things in the Inspector:

  • Mask: player (instead of mobs) — now it only hits the player.
  • Different sprite color so players can read danger at a glance.

The script is identical — only layers and art change. Adjust its hit code to tell the player it's been hit instead of instantly deleting it:

func _on_body_entered(body):
	body.take_damage()   # the player script decides what being hit means -- see Health and Lives
	queue_free()

Boss scene: it never moves, so it's simple — no CharacterBody2D needed:

Boss            (StaticBody2D)   Layer: mobs, Mask: (none)
├── Sprite      (Sprite2D)
├── Shape       (CollisionShape2D)
└── ShootTimer  (Timer)          Wait Time: 1.5, Autostart ✓

Script on the Boss root — connect the Timer's timeout signal (Spawning and Timers):

extends StaticBody2D

@export var bullet_scene: PackedScene   # drag boss_bullet.tscn here

func _on_shoot_timer_timeout():
	var player = get_tree().get_first_node_in_group("player")
	if player == null:
		return   # player is dead — stop shooting

	var bullet = bullet_scene.instantiate()
	bullet.global_position = global_position
	bullet.direction = (player.global_position - global_position).normalized()
	get_tree().current_scene.add_child(bullet)
  • (player.global_position - global_position).normalized() — the aiming line. Target minus me = direction to target; normalized() makes it length 1 so speed stays in charge.
  • Add the player to the "player" group: select the Player root → Node dock → Groups → type player → Add. That's how the boss finds it without a hard-coded path.
  • The null check stops the boss from crashing (and rudely shooting) after the player dies.

Player side: the player needs the take_damage() function the bullet calls. Build the real one — hearts, i-frames, respawn — in Health and Lives. The bare minimum to get bullets working today:

# in the player script
signal hit_by_bullet

func take_damage(_amount = 1):
	hit_by_bullet.emit()   # wire this to lives / game over (see Score and UI)
	# or for instant death: queue_free()

Tuning the dodge: the whole game feel lives in two numbers — boss bullet speed (slower = more readable, try 300) and ShootTimer wait time (shorter = more frantic). Slow bullets + fast timer = bullet-hell curtain; fast bullets + slow timer = sniper duel. Both are fun; they're different games.

Want the player to shoot back? Give the player Example 1's shoot code (aimed with the mouse if you like: direction = (get_global_mouse_position() - global_position).normalized()), give the Boss a health variable, and have the player-bullet's body_entered call a take_damage() on it instead of queue_free(). Boss fight complete.

⚠️"My bullets hit the wrong things"

It's always layers. Player bullet: Layer bullets, Mask mobs. Boss bullet: Layer bullets, Mask player. Neither bullet should mask bullets — otherwise bullets annihilate each other mid-air (which, granted, is a mechanic in some games — do it on purpose or not at all).
