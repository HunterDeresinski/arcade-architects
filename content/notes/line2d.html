Draws a line through a list of points. Lasers, rope, grappling hooks, motion trails, aim indicators, and drawing on the screen.

#The basics

Add a Line2D. In the editor, use the pencil tool to click points, or set them from code:

$Line2D.points = [Vector2(0, 0), Vector2(100, 0), Vector2(100, 100)]
PropertyDoes
Pointsthe list of Vector2s it connects
Widththickness in pixels
Width Curvethickness along the line — taper a trail to a point
Default Colorcolour
Gradientcolour along the line — fade a trail out
Texture + Texture Modetile an image along it (rope, chain)
Joint / Begin / End Cap Modeset all three to Round for smooth ends
Antialiasedsmoother edges

Points are local to the Line2D, so a line parented to a moving object moves with it. Use to_local() when converting from world positions.

#What people actually build with it

A laser beam, with RayCast2D:

func _physics_process(_delta):
	$Ray.force_raycast_update()
	var end_local: Vector2
	if $Ray.is_colliding():
		end_local = $Line.to_local($Ray.get_collision_point())
	else:
		end_local = $Line.to_local($Ray.to_global($Ray.target_position))
	$Line.points = [Vector2.ZERO, end_local]

The beam stops exactly at the wall. Add a spark emitter at the impact point and it looks properly expensive.

A motion trail behind a fast object (Dash and Double Jump):

extends Line2D

@export var max_points = 15
@export var target: NodePath

func _process(_delta):
	add_point(to_local(get_node(target).global_position), 0)
	if get_point_count() > max_points:
		remove_point(get_point_count() - 1)

Set the Gradient to fade to transparent and the Width Curve to taper, and you have a comet tail. Keep the Line2D as a sibling of the player, not a child, or the trail drags along with it.

A grappling hook or rope:

func _process(_delta):
	if hooked:
		$Rope.points = [Vector2.ZERO, $Rope.to_local(hook_point)]
		$Rope.show()
	else:
		$Rope.hide()

An aim indicator — a dotted line showing where a shot will go. Use a dashed texture with Texture Mode = Tile (Making Bullets).

A trajectory preview (Angry Birds style) — simulate the arc and plot the points:

func preview(start_velocity: Vector2):
	var pts = []
	var pos = Vector2.ZERO
	var vel = start_velocity
	for i in 30:
		pts.append(pos)
		vel += Vector2(0, 980) * 0.05
		pos += vel * 0.05
	$Aim.points = pts

Player drawing — let the player draw a path with the mouse:

func _input(event):
	if event is InputEventMouseMotion and Input.is_action_pressed("draw"):
		$Line.add_point($Line.to_local(event.global_position))

A connect-the-dots or wire puzzle, or a snake body drawn as one line (Grid-Based Movement).

#Useful methods

$Line.add_point(pos)          # append
$Line.add_point(pos, 0)       # insert at the front
$Line.remove_point(index)
$Line.set_point_position(i, pos)
$Line.get_point_count()
$Line.clear_points()

#Common problems

ProblemFix
Nothing visibleFewer than 2 points, Width is 0, or colour is transparent
Line is in the wrong placePoints are local — convert with to_local()
Trail follows in a clumpLine2D is a child of the moving object. Make it a sibling
Corners look spikySet Joint Mode to Round
Slows down over timePoints accumulate forever — cap them with remove_point
Gradient does nothingGradient needs at least two colour stops
